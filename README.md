**从概念到可拍剧本、从烂稿到精准诊断——一条完整的故事管线。方法论不是拼凑的写作技巧，而是作者自著的四部写作理论（《人物篇》《命运篇》《故事天演论》《文学天演论》）的操作化。**

```
概念 → 原创剧本流（七阶段长出可拍剧本）
小说 → 改编流（保留叙事功能，更换信息载体）
成稿 → 小说理论评审（红黄牌诊断 + W 值打分）
剧本 → 表演层视频提示词（演什么、怎么演、不演什么）
```

---

## 你是不是也遇到过这些？

- 脑子里有个**很妙的概念**，却不知道从哪开始——试了几个开头都不对
- 小说写完总感觉**"哪里不对"**，但说不清问题出在哪一章、哪个人物
- 改编剧本时，把小说**"翻译"**成了小说，而不是电影
- 给 AI 写视频提示词，画面永远**差一点"活人感"**
- 结尾总是**"结束了"**，而不是**"没结束"**

这套技能的回答不是"多读多写"，而是四部理论给出的可判定标准——**每个问题都能定位到一条规则、一个证据、一个改法**。

---

## 四件套

### 📖 novel-to-screen-adaptation — 改编流（小说 → 剧本）

> 改编不是保留原句，是保留原句背后的叙事功能，并更换信息载体。

命题 → 发动机 → 屏幕物件 → 场景卡 → 节拍表 → 可拍剧本。每一步有硬规则（动作占比 ≥40%、对白 ≤3 句、无不可拍词），导演模式驱动，产出带签核。

### ✍️ novel-original-writing — 原创剧本流（概念 → 剧本）

> 让一个想法变成别人愿意继续追问的局面——入口很低，经验很高。

种子期（欲望八象 × 六变一常 × 低入口高经验）→ 麻雀世界观 → 人物五组问题（私/处/执/为/已 38 问）→ 二十四节气结构 → 场景卡 → 表演注入 → 余震收尾。质量门 20 条，与导演共创推进。

### 🔍 novel-review — 小说理论评审（成稿 → 诊断）

> 读后感回答"我喜不喜欢"；评审回答"问题出在哪、违反了哪条理论、证据在哪、怎么修"。

四层扫描（人物/结构/结局/文笔）+ 红黄牌分级 + **天演评分**（继承神之公式 $W_{Story}=[(T\times\frac{M\cdot V\cdot \eta}{R^2})-S]\times e^{\xi}$，判据接当前理论）。每条结论可追溯到理论条目。

### 🎭 video-prompt-adapter — 表演层视频提示词（剧本 → 成片指令）

> 好的视频提示词是导演的表演指令：告诉模型演什么、怎么演、不演什么。

角色内在 / 表演心理学 / 微表演词汇 / 否定约束——表演驱动，不是画面描述。

## 理论的招牌（为什么这套不一样）

- **二十四节气验收句**："这段写得像夏至，但裂口没照出来"——节奏火候变成可判定检查
- **私/处/执/为/已 38 问**：同一个故事前提，换一个"私"就长出完全不同的故事
- **失候清单 19 条**：该藏的时候说太多、该杀的时候舍不得断——问题一勾一个准
- **大雪 gate**：结尾不是把话说尽，是余震留雪下——"真正的余震不是留坑，余震是意义没有耗尽"
- **W 值打分**：M·V·η 乘积、R² 平方级杀伤、ξ 决定上限——好故事有物理定义

## 快速开始

```text
"把这个小说改编成剧本"      → 改编流
"用原创剧本流写个概念"       → 原创剧本流
"帮我看看这部小说问题出在哪"  → 小说理论评审
"给我写个视频提示词"         → 表演层
```

**方式一：插件市场安装（推荐）**

```text
/plugin marketplace add juemin4-source/novel-skills
/plugin install novel-skills@novel-skills
```

**方式二：手动复制**

四个目录平级复制到项目的 `.claude/skills/`（或用户级 `~/.claude/skills/`），保持平级即可——技能间引用为相对路径。
