# Scene Card Template

## Format

```markdown
## S-{id}: {scene_name}

**来源:** {source_chapter}
**地点:** {location} | **时间:** {time}
**人物:** {characters}

---

### 目标
{character} 想要 {objective}
（必须具体、可见、可拍）

### 阻碍
{obstacle}
（什么挡在目标和结果之间？❌ "命运" ✅ "门锁了"）

### 冲突
{conflict}
（目标和阻碍的碰撞——必须是外部可见的！
 ❌ "内心挣扎" ✅ "两人抢一把枪" / "门打不开，脚步声越来越近"）

### 变化
{character} 从 {state_before} → 变成 {state_after}

### 信息揭示
{information_reveal}
（观众在这场戏中知道了什么不知道的信息？）

### 关系变化
{relationship_shift}
（角色之间的距离是靠近了还是远离了？）

### 屏幕物件
{screen_object}
（这场戏是否引入/回收某个核心物件？）

### 内心外化
{inner_info_externalized}
（小说中的内心活动如何外化为可见行动？）

### 视觉策略
{visual_strategy}
（色调、镜头节奏、关键画面）

### 功能
{scene_function}
（这场戏在整集中完成什么？必须唯一。）

### 结束状态
{ending_state}

### 可删
{removable}
（如果删掉这场戏，下游会不会断？如果不会，删。）
```

---

## Validation Checklist

```
[ ] 目标是否明确具体？（角色A想要[具体事物]，不是"想要幸福"）
[ ] 阻碍是否具体可拍？（不是"命运"而是"门锁了；敌人进来了"）
[ ] 冲突是否外部可见？（不是"内心挣扎"，是"两人对峙"）
[ ] 是否有关键信息揭示？（观众知道了什么新信息？）
[ ] 是否有关系变化？（靠近/远离/反转）
[ ] 结束状态是否明确？（角色A从X状态变成Y状态）
[ ] 功能是否唯一？（和其他场不重复）
[ ] 如果"可删=yes"，是否真的可以删？
```

## Hard Rules

1. **冲突必须外部可见**——不是心中矛盾，是两人之间/人和环境/人和系统的碰撞
2. **变化必须有**——如果角色状态没有变化，这场戏为什么存在？
3. **功能必须唯一**——看场景卡片就知道它在整集中的位置
4. **如果 conflict 写不出来 → 这场戏不该独立成场**，合并到相邻场
