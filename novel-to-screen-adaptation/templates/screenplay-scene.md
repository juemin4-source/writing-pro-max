# Screenplay Scene Template

## Format

```markdown
### S-N 场景名称

内/外 · 地点 · 时间

人物：角色列表

**动作描述**
可见的、可拍的画面描述。
不能用"她感到/她意识到/她记得"。
用身体动作、环境反应、物件细节来传递信息。

对白和动作的关系：对白打断动作，动作打断对白。
不要超过 3 句连续对白没有动作打断。

---

**角色名：**
对白内容（必须执行动作，不能解释内心）

（动作/方向）
更多对白

**角色名2：**
对白内容

---

转场：淡出/切黑/跳切
```

---

## Good Example（好例子）

```markdown
### S-1 盖娅实验室 · 天衣

内 · 盖娅实验室核心舱 · 日

人物：塞巴斯蒂安、娜伊玛、天衣（半机械体）

冷调金属墙壁。三台机械臂从天花板垂下，夹着一个年轻女性的身体——天衣。
她的躯体一半是血肉，一半是机械。银色的线路像脉络一样在皮肤下蔓延，
随呼吸微弱发光。

塞巴斯蒂安站在控制台后，条纹暗纹西服，指尖转动一只银壳怀表。
他没有看天衣。他在看监控屏上的数据曲线。

娜伊玛站在他旁边半步之后，手指悬在键盘上，没有落下。

**塞巴斯蒂安：**
（仍盯着屏幕）
阈值2.4。启动。

娜伊玛的手指落下。

电流涌入天衣的身体。她无声地张嘴，颈部肌肉绷紧，手指在金属台面上
刮出刺耳声响。

**娜伊玛：**
（压低声音）
到极限了。

塞巴斯蒂安停下怀表，合上表盖。金属撞击声清脆。

**塞巴斯蒂安：**
极限？

他转身，第一次看向天衣。他的表情像是在观察一台运行异常的机器。

**塞巴斯蒂安：**
在盖娅工程，我们不接受这个词。
（对娜伊玛）
继续。

电流增强。天衣的身体弓起，指甲断裂。实验室闪烁红灯。

娜伊玛低头，不再看。

---

跳切
```

## Bad Example — What Not To Do（坏例子）

```markdown
### S-1

盖娅实验室，塞巴斯蒂安在操作机器。天衣被测试。

**塞巴斯蒂安：**
调整神经连接器至阈值2.4，启动痛觉测试。

电流涌入天衣的身体。她感到很痛苦。

**女科学家娜伊玛：**
（不安）
到极限了。

**塞巴斯蒂安：**
极限？在盖娅工程，我们不接受"极限"这个词。你参加过马拉松吗？人类从大海中走出来，走到一颗颗星球。每一次突破都是对极限的回应。我们创造，我们适应，我们超越。
继续。

电流增强。天衣感到更痛苦。
```

### 坏在哪？

| 问题 | 坏例子 | 好例子 |
|------|--------|--------|
| 场景标题不完整 | `### S-1` | `### S-1 盖娅实验室 · 天衣` |
| 场景缺少内/外/时间 | 无 | `内 · 盖娅实验室核心舱 · 日` |
| 动作用"她感到" | `她感到很痛苦` | 用身体细节：无声张嘴、肌肉绷紧、指甲断裂 |
| 动作太概括 | `塞巴斯蒂安在操作机器` | 具体动作：把玩怀表、合上表盖、第一次看向天衣 |
| 对白太长 | 50字独白 + 马拉松类比 | 压缩到3句 + 打断怀表动作 |
| 对白解释内心 | 独白解释哲学 | 用动作（合上表盖）替代解释 |
| 缺少人物关系 | 无 | 娜伊玛的手指悬在键盘上（犹豫）→ 低头不看（内疚） |
| 没有转场 | 无 | `跳切` |

## Hard Rules for Template Usage

1. **场景标题必须包含名称**（不只是 `S-1`，还要 `S-1 天衣`）
2. **必须有内/外 · 地点 · 时间**
3. **动作描述占比 ≥ 40%**
4. **没有"她感到/她意识到/她记得"类描述**
5. **每段对白 ≤ 3 句**（否则打断或压缩）
6. **对白必须有潜台词**（不直接说意图）
7. **每个场景必须有转场**（至少 `---`）
8. **开场第一个画面必须有视觉 hook**（30秒内建立世界）
