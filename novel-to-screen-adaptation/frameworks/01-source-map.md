# 01 — Source Map

## Purpose

对小说进行机械拆分和索引。脚本辅助，不负责戏剧理解。

## Output Fields

- 章节列表（id / title / line_range）
- 主要人物列表（出现章节 / 频次）
- 地点列表（出现章节 / 频次）
- 高频物件（出现章节 / 频次）
- 疑似场景边界（时间/空间/人物变化处）

## Mechanical (Script-Assisted)

```
- 按章节标题拆分
- 统计章节长度
- 提取人物（命名实体识别）
- 提取地点
- 提取高频名词（潜在物件）
- 标记场景边界（时间/空间切换处）
```

## Boundary

机械拆分负责结构，不负责戏剧理解。
