# 10 — Beat Sheet

## Purpose

Beat sheet 先于剧本正文。每场戏列出节拍序列，再展开。

## Beat Structure

```
BEAT N: [动作/事件]
  TURN: [人物状态/目标变化]
EXIT: [场景出口状态]
```

## Example

```
BEAT 1: 晨进入房间，发现有人来过
BEAT 2: 他检查物品，确认是女主留下的信号
BEAT 3: 门外传来脚步声
BEAT 4: 晨快速收起证据，换了一副面孔
        TURN: 从调查者转为伪装者
BEAT 5: 门开了，晨笑着转身
EXIT: 危机暂时避开，但晨知道自己被监视了
```

## Hard Rule

先 beat sheet，再剧本正文。跳过 beat sheet 直接写对白 = 剧本降级。
