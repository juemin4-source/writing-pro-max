# 08 — Plot Node & Set-Piece Design

## Purpose

每集拆出情节节点，识别核心场面。

## Plot Nodes

| Node | Function |
|------|----------|
| Cold Open | 开场钩子 |
| Inciting Incident | 触发事件 |
| First Turn | 第一次转折 |
| Midpoint | 中点（假胜利/假失败）|
| Crisis | 最大危机 |
| Climax | 高潮对决 |
| Ending Hook/Payoff | 结尾钩子/回收 |

## Set-Piece Criteria

Set-piece 不是普通大场面。它必须同时完成：

```
✅ 视觉记忆点（观众会记住的画面）
✅ 人物转折（角色发生变化）
✅ 信息揭示（揭示关键信息）
✅ 主题测试（命题被验证）
✅ 后续推进（为下一步铺路）
```

## Hard Rule

把视觉奇观当成 set-piece 是错误的。视觉是手段，叙事才是目的。
