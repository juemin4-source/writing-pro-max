# 11 — Screenplay Draft

## Purpose

最后一步。在完成 episode map → plot node → scene card → beat sheet 之后，写剧本正文。

## Screenplay Format

每场剧本包含：

```
场景标题: 内/外 · 地点 · 时间
人物: 出场角色
动作: 可见行动
对白: 角色说的话（必须执行动作）
转场: 切出方式
```

## Screenplay Rules

### 动作

```
❌ "晨感到一阵不安"（不可拍）
✅ "晨停下脚步，他咽了口唾沫，指节捏得发白"（可拍）
```

```
❌ "她意识到自己被骗了"（不可拍）
✅ "她翻开包，手僵住了。慢慢抬起头，对面的人已经不见了。"（可拍）
```

### 对白

```
❌ "我很矛盾，我既想相信她又怕被背叛"（解释内心）
✅ "枪给你。"（递出枪）"不用谢我，我只是懒得背了。"（行动+防御）
```

```
❌ "这座城市分成三个区域，上层区很安全"（信息 dump）
✅ "你确定这条路安全？"（问）
  "不太确定。"（答）
  "那你怎么还往这走？"
  "因为其他路更不安全。"（在冲突中释放信息）
```

### 节奏

```
追杀戏: 短句，少描述，快切
对决前: 长停顿，细节描述，沉默
情感戏: 物件承载，不多写
```

## Beat Sheet Before Draft

每场戏必须先写 beat sheet，再写正文：

```
BEAT 1: 晨进入房间，发现有人来过
BEAT 2: 他检查物品，确认是女主留下的信号
BEAT 3: 门外传来脚步声，不是一个人
BEAT 4: 晨快速收起证据，换了一副面孔
        TURN: 从调查者转为伪装者
BEAT 5: 门开了，晨笑着转身
EXIT: 危机暂时避开，但晨知道自己被监视了
```

然后才展开成完整剧本。

## Hard Rules

1. 先 beat sheet，再剧本正文
2. 少解释，多行动
3. 用物件承载心理
4. 用场面承载主题
5. 用关系变化承载情绪
6. 用沉默和选择替代直白台词
7. 不把小说内心独白直接改成对白
