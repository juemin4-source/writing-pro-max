# 03 — Main Proposition

## Purpose

总结小说的核心命题，不是空泛主题词。命题必须可改编——它必须能通过人物的选择和行动来证明。

## Format

```
当【某类人物】在【某种压力系统】中遭遇【核心冲突】时，
他/她必须通过【关键选择】证明【主题命题】。
```

## Example

```
当一个习惯独自承担一切的战士，在必须信任他人才能活下来的战场上，
他必须通过放手控制证明：真正的力量不是独自扛，而是相信别人会接住你。
```

## Output Fields

| Field | Required | Description |
|-------|----------|-------------|
| main_proposition | ✅ | 核心命题句 |
| anti_proposition | ✅ | 反命题（主角如果选错了会证明什么）|
| how_proven | ✅ | 哪些关键选择证明了命题 |
| how_recovered | ✅ | 结尾如何回收命题 |
| non_negotiable_core | ✅ | 改编中绝对不能丢失的核心 |

## Hard Rules

1. 禁止空泛标签（"爱"、"复仇"、"自由 vs 控制"）
2. 命题必须能用一场戏证明
3. 必须有对应的反命题
