# 06 — Interior-to-Screen Translation

## Purpose

把小说里的不可拍信息转成可拍信息。这是本 skill 的核心模块。

## 8 Converters

### 1. Interior → Action

内心转行动。角色想什么不重要，做什么才重要。

```
小说: 晨心里很矛盾，他既想相信她，又害怕被背叛。
屏幕: 晨把枪递给女主，手没有立即松开。他看了她两秒，然后放手转身。
      不需要对白，动作完成了信任与犹豫的表达。
```

### 2. Motivation → Objective

深层动机转当场目标。观众不需要知道角色为什么来，只需要知道他来干什么。

```
小说: 晨之所以接下这个任务，是因为他想找到当年的真相。
屏幕: 晨推开任务档案，目光停留在最后一页。
      对队长说："我接。" 起身离开。不需要解释原因。
```

### 3. Exposition → Pressure

背景说明转场面压力。观众在压力中自己吸收背景，不需要旁白。

```
小说: 这座城市被分为三个区域，上层区治安良好，下层区无法无天。
屏幕: 晨开车经过边界检查站，车窗外的建筑从光鲜逐渐变为破败。
      后视镜里，一辆治安巡逻车停在路口没有跟过来。
      不需要对白，空间的对比完成了世界观说明。
```

### 4. Theme → Scene Test

主题转具体场面测试。主题不是在台词里讲出来的，是角色在艰难选择中证明的。

```
命题: 信任 vs 自保
测试: 女主被敌人抓住。晨有机会安全撤离，但选择留下。
      不解释为什么留下，做留下这个动作本身就是在证明命题。
```

### 5. Relationship → Blocking / Choice

关系转站位、选择、靠近、回避、牺牲、背叛。关系不是说出来的，是物理距离和关键选择完成的。

```
小说: 晨和女主的关系已经疏远了。
屏幕: 在狭窄的走廊里，晨侧身让女主先过。
      两人没有对视。走廊很窄，但中间的间隙足够再站一个人。
```

### 6. Prose Style → Audio-Visual Strategy

文风转镜头、光线、节奏、声音、沉默。

```
密集恐惧的文风 → 快速跳切 + 浅景深 + 环境音压过头
舒缓抒情的文风 → 长镜头 + 柔光 + 环境音 + 沉默
冷酷简练的文风 → 固定机位 + 硬光 + 空旷空间回声
```

### 7. Plot Event → Dramatic Beat

情节事件转戏剧节拍。事件本身不重要，它对人物的冲击才重要。

```
事件: 大楼爆炸了。
节拍: 晨从废墟中爬出，耳鸣，听不见声音。
      他回头寻找女主，看到一只断手（不是她的）。
      这个节拍不需要爆炸特效有多炫，需要的是他寻找的过程和不确定的结果。
```

### 8. Symbol → Prop / Image / Sound Payoff

象征转道具、画面、声音回收。

```
小说: 晨总做同一个噩梦，梦见自己溺水。
屏幕: 第三幕决战开始时，晨被敌人按进水里。
      挣扎时他看到水面上的光——和噩梦中的画面一模一样。
      这个回收不需要解释，画面本身完成了意义传递。
```

## Translation Record Format

```json
{
  "converter": "Interior → Action",
  "source": "晨内心矛盾，既想相信又害怕背叛",
  "screen": "晨把枪递给女主，手没有松开，看了她两秒，放手转身",
  "loss": "失去直接的心理描写",
  "fidelity": "行动中保留了犹豫和最终决定",
  "compensation": {
    "type": "performance",
    "plan": "演员需要在不松开手的动作中完成'犹豫'的表达。不需要额外补偿。"
  }
}
```

### Compensation Field

每条转换必须包含补偿方案。补偿回答一个问题：**"丢失的信息用什么东西替代了？"**

| 补偿类型 | 什么时候用 |
|---------|----------|
| `visual_push` | 信息适合通过镜头语言传达 |
| `sound_design` | 信息适合通过声音/沉默传达 |
| `object_focus` | 有个物件能承载丢失的信息 |
| `dialogue_insert` | 把背景信息挪到对话中自然揭示 |
| `sequence_resequence` | 把信息放到更自然的位置释放 |
| `performance` | 依赖演员表演完成传达 |
| `delayed_reveal` | 信息不在这里说，在后面让观众自己发现 |
| `montage` | 快速剪辑能承载 |
| `none` | 确认无影响，干净删除 |

## Hard Rules

1. 重要心理信息必须找到屏幕载体
2. 不能只让角色用台词解释自己内心
3. 每条转换记录必须包含 `loss` 和 `fidelity`
