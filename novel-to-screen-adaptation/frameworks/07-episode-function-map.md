# 07 — Episode Function Map

## Purpose

把小说章节重组为剧集功能。不能机械地一章一集。

## Episode Function Fields

| Field | Description |
|-------|-------------|
| episode_id | 剧集ID |
| source_chapters | 来源小说章节 |
| episode_title | 剧集标题 |
| episode_function | 本集让观众知道什么 |
| protagonist_state_start | 主角开始状态 |
| protagonist_state_end | 主角结束状态 |
| main_reveal | 本集揭示的主要信息 |
| main_conflict | 本集核心冲突 |
| screen_objects_used | 使用的屏幕物件 |
| cliffhanger_payoff | 结尾钩子或回收 |

## Hard Rule

章节是叙述单位，剧集是观看推进单位。不能机械搬运。
