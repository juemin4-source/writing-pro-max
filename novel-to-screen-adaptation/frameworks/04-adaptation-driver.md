# 04 — Adaptation Driver & Screen Format

## Purpose

找到改编发动机（这个故事靠什么推动观众看下去），判断适合的影视形态。

## Driver Types

| Driver | 核心 | 适合改编成 |
|--------|------|-----------|
| Character-Driven | 人物欲望/缺陷/关系变化驱动 | 电影, 迷你剧 |
| Concept-Driven | 核心母题/象征系统/世界规则 | 电影, 概念预告片 |
| Power-Game-Driven | 权力结构/利益交易/话术博弈 | 长剧集 |
| Mystery-Mechanism-Driven | 信息差/线索/反转驱动 | 迷你剧, 剧集 |
| Emotion-Ritual-Driven | 情感关系/仪式/选择驱动 | 电影, 竖屏短剧 |
| Identity-Revelation-Driven | 身份揭露/自我认知崩塌 | 电影, 迷你剧 |
| Contained-World-Reveal | 封闭世界逐步揭露 | 剧集, 迷你剧 |

## Screen Format Decision

| Format | Runtime | Episode Count | Scene Density |
|--------|---------|---------------|---------------|
| 电影 | 90-120min | 1 | 高 |
| 迷你剧 | 30-50min × 4-8 | 4-8 | 中 |
| 长剧集 | 40-60min × 10-24 | 10-24 | 中-低 |
| 竖屏短剧 | 1-3min × 30-100 | 30-100 | 极低 |
| 15s AI 视频样片 | 15s × N | 不限 | 极简 |
| 概念预告片 | 2-3min | 1 | 选集精华 |
| 分镜验证片段 | 30-60s | 1 | 单场景 |

## Hard Rules

1. 不同影视形态改变节奏、集数、场面密度和输出结构
2. 必须输出 driver + format 判断，否则下游无法适配
