# Negative Constraints — 否定约束库

## Purpose

防 AI 通病。官方手册的禁止项零散出现（30 秒公式的禁止项、静音约束、版权规避）；本文件按**题材**系统化，让"不演什么/不生成什么"成为可配选的清单。

## 语法三则

### 1. 逐项写，不笼统
- ✅ "无字幕、无 BGM、无旁白、无环境杂音"（逐项）
- ❌ "不要声音"（笼统，模型无法分解执行）

### 2. 四维全覆盖（官方禁止项结构）

| 维度 | 查什么 | 示例 |
|------|--------|------|
| 声音 | 字幕/旁白/BGM/环境杂音 | 无字幕、无 BGM、无旁白 |
| 字幕 | 画面内文字/乱码字幕 | 全程无字幕、无任何文字 |
| 行为 | 多余台词/动作失控/情绪直给 | 禁止多余台词、禁止大幅度肢体动作 |
| 崩坏高发处 | 五官/肢体/穿模/物理逻辑/重复人物 | 禁止五官崩坏、禁止多手指、禁止穿模 |

### 3. 力度分级

| 级 | 写法 | 用途 |
|----|------|------|
| 必须（无条件） | "全程禁止……" | 字幕/BGM/版权 |
| 时段限定 | "仅在 X 秒后允许……，禁止提前" | 特效时机/情绪爆发点 |
| 弱约束 | "避免……倾向" | 风格偏好类 |

---

## 通用约束基线（所有题材先过这层）

```
【声音维度】无字幕；无 BGM（如需保留对白，写"删除 BGM 仅留人声"）；无旁白；无环境杂音（如需环境声，逐项列出保留项）。
【字幕维度】全程不出现任何文字、字幕、LOGO、水印。
【行为维度】禁止多余台词；禁止动作幅度失控；禁止角色做出超出人设的夸张反应。
【崩坏高发处】禁止五官崩坏、手部畸形（多指/手指黏连）、肢体穿模；禁止物体凭空出现；禁止人物变形（脸/体型/服装随机变化）；禁止重复人物（克隆脸）。
```

## 分题材清单

### 现实/都市情感（写实人）

AI 通病：网红脸/AI 美女、影楼感、表演直给、场景样板间

```
- 一致性：不换脸、不漂移、不变成网红脸或 AI 美女；保持脸型/五官/年龄感/发型/气质一致
- 质感：不要影楼感、不要写真感、不要过度精致、不要强 AI 感
- 表演：不要夸张哭喊、不要直给情绪、不要表情包式演法
- 场景：不要像样板间——要有生活痕迹和有序的乱（磨损、杂物、使用过的痕迹）
- 皮肤：保留真实的微细毛孔与肌肤纹理（可增加雀斑/瑕疵），不要塑料反光
```

### 科幻/机甲/赛博

AI 通病：软体变形、现代元素乱入、版权 IP、结构穿模

```
- 机械刚性：禁止机甲结构在运动中软体动物般扭曲/穿模，必须保持金属刚性
- 物理：禁止液体/金属反光不符合物理规律；禁止凭空消失或出现
- 版权：规避《变形金刚》《创战纪》等已知版权 IP 元素（显式写）
- 视觉：禁止 3D 油腻感；禁止现代日常元素混入科幻场景
```

### 武侠/国漫

AI 通病：3D 油腻、武打拖泥带水、特效时机失控

```
- 画风：禁止 3D 油腻感（严格保持 2D/三渲二画风）
- 动作：禁止武打动作拖泥带水；禁止肢体穿模扭曲
- 时机：水墨/特效只能在指定秒段出现，禁止提前；禁止"圆月没淡化完酒碗就出现"类时序错误
- 台词：禁止生成任何字幕或多余台词
```

### 惊悚/悬疑

AI 通病：恐怖元素无铺垫、角色崩坏、信息过度暴露

```
- 铺垫：禁止怪物/人影毫无征兆出现（须有视线/声音/环境先导）
- 氛围：禁止突然变喜剧或明亮色调；保持压抑节奏
- 信息：禁止提前暴露悬念答案（关键信息只能在指定秒段揭示）
- 声音：环境音逐项写（雨声/电流声/脚步声），禁止随机 BGM
```

### 动画/卡通（含 3D 动画电影风）

AI 通病：渲染风格漂移、比例错误、角色设计变动

```
- 风格统一：禁止任何画面出现风格偏移（毛毡风就全程毛毡风）
- 角色：禁止换脸/变形/比例错误；禁止服饰、年龄、外观随机变化
- 逻辑：禁止镜头间时间/空间/人物位置/光照不连续
- 文字：除指定字幕外全片禁止任何文字
```

### 儿童内容

AI 通病：IP 侵权、危险元素、恐怖元素、闪烁

```
- 版权：禁止任何 IP 相关元素、现有动画/电影/游戏/漫画角色、品牌 logo、商标、版权图案、标志性服装/道具、可识别品牌名称、水印——所有角色/道具/场景必须原创
- 安全：无危险动作、无恐怖元素、无复杂剧情
- 生理：无强烈闪烁、无低清晰度、无画面闪烁
```

### 电商/广告

AI 通病：版式漂移、乱码文字、道具乱入、颜色不一致

```
- 版式：分栏/排版结构全程保持不变
- 文字：全程禁止任何文字/字幕/标语/水印/logo/额外标注（或指定语言文字）
- 道具：禁止多余道具出现；背景道具与主体关系稳定
- 一致性：产品颜色/材质/logo 全片统一；灯光阴影风格统一
- 镜头：如需固定机位，写"镜头全程固定不推拉摇移"
```

### MV/音乐卡点

AI 通病：画面与节拍错位、BGM 叠加、情绪断档

```
- 节拍：禁止画面节奏与音乐情绪脱节（关键动作标注秒数/帧数）
- 声音：无字幕；如需干净底片写"纯视觉画面，完全静音"（供后期配乐）
- 转场：禁止生硬切镜、禁止物体凭空出现
```

### 纪实/风光/空镜

AI 通病：人造物乱入、画面断层、过度特效

```
- 内容：禁止出现人类或人造物（按题材：禁现代交通工具/建筑/人物入镜）
- 连续性：禁止水面/光线过渡时画面闪烁与断层
- 真实：禁止过度调色失真；物理（丁达尔、折射）必须符合真实光学规律
- 声音：环境音逐项写；无 BGM、无旁白
```

### 多人戏（群像/双人）

AI 通病：双胞胎脸、特征互串、服装张冠李戴、缝合怪

```
- 独立：每个角色面部特征独立，禁止长相趋同（双胞胎脸）、禁止特征互串
- 服装：禁止服装/配饰在不同角色间互串；各自设定全程锁定
- 肢体：禁止肢体交叠变形（多手多脚缝合怪）；人物间距保持
- 身份：禁止身份混乱（谁是谁全片一致）；主次分明
```

## 时间限定约束（高级写法）

否定约束可以**精确到秒/帧与事件时序**：

```
- 秒段限定："水墨化效果只能在 25 秒之后随'咔哒'声出现，禁止提前出现"
- 事件时序："禁止圆月没有淡化完毕，酒碗就出现"
- 状态限定："禁止眼泪提前滴落"（表演核心行的时序否定）
- 全片统一："全片（15 秒）统一修改保持一致，仅在第 5-8 秒发生变化"
```

## 静音约束专项

要求静音时**必须逐项写**，官方验证有效写法：

```
✅ 全程无背景音乐（不要 BGM）、静音生成、无旁白、无环境杂音——完全静音的纯视觉画面
✅ 只保留：真实环境音（雨打玻璃声、细微的环境音）逐项列出保留项
✅ 删除 BGM 仅保留人声（分离/移除 BGM 场景：还要加"画面、字幕、画质、色调、构图全部保持不变"）
```

## 版权与合规

- 版权规避显式写：`规避《XXX》等已知版权 IP 元素`
- 儿童内容：IP/logo/商标/水印全禁 + 原创声明
- 不用负面词清单（如"不出现黑色"这种极端词）——写具体的、可判定的约束

## 与表演层的搭配

否定约束是表演层的"围栏"——防的是同一个通病的两面：

| 表演层要求 | 配套否定约束 |
|-----------|-------------|
| 克制的羞意 | 不要夸张哭喊、不要直给情绪 |
| 细腻微表情 | 不要表情包式演法、不要大幅度肢体动作 |
| 生活气场景 | 不要像样板间、不要过度精致 |
| 真实皮肤 | 不要塑料感、保留毛孔纹理 |

## 检查清单

- [ ] 四维齐全（声音/字幕/行为/崩坏高发处各 ≥1 项）
- [ ] 与题材匹配（按上表选配，不套通用层了事）
- [ ] 静音要求逐项写，不写"不要声音"
- [ ] 有时间限定的约束写了具体秒段
- [ ] 版权规避显式（涉及已知 IP 时）
- [ ] 每条可判定（"不要过度精致"这类审美词配了具体参照物）
