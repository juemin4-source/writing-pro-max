# Seedance 2.5 官方 Prompt 格式参考

> 基于官方 2.5 手册整理（2026-08-01，895 行原文 → 本文件为格式层提炼）。07 的提示词必须对齐此格式；表演层方法见 performance-direction.md；平台规格与质量门见 SKILL.md。

## 一、公式体系（八套，全部带必填词）

### 1. 基础公式
```
完整提示词 = 【素材描述】（素材编号+用途）+【一句话概述】（主体+地点+事件+题材/风格+特殊运镜）
            +【具体情节描述】（分时间轴/故事线；每段 = 正向[画面+运镜+动作+台词+音效] + 反向[不要字幕/BGM]）
            +【全局补充】（结尾：贯穿元素 + 全局禁止项）
```

### 2. 30 秒长视频公式（三层）
```
总述名称（一句话定基调）
→ 模块一【多模态参考层】：基于上传的[素材类型]，严格保持@图1的人物[面孔/特征]一致性，
  保持@图2的[构图/白模/空间关系]一致，严格锁定人物站位
→ 模块二【全局设定】：[基础环境与质感]+[视觉风格]+[镜头语言]+[人物造型]+[表演核心]+[禁止项]
  （禁止项从声音+字幕+行为+容易崩坏处入手）
→ 模块三【时间戳剧本分镜】（见 §二）
```

### 3. 超长视频公式（30-180s）
```
基础公式 + 最开头加【全局参数】（时长/画幅）。重点：素材@清楚 + 故事描述清楚
```

### 4. 真人人物公式（7 维）
```
[年龄/种族]（具体岁数+国籍+风格+脸型）
+ [肤色/皮肤质感]（冷暖+肤色+质感+强制保真后缀："保留真实的微细毛孔与肌肤纹理（可增加雀斑/瑕疵）"）
+ [面部细节特征]（眼型+眉骨+鼻梁+唇形+下颌线，至少 3-4 点）
+ [眼神/灵魂]（眼神形容词+目光传达+底层情绪）
+ [发型/发色]（发色+状态+发型名词+环境互动）
+ [服装/服装质感]（版型+颜色+名词+布料材质/新旧+穿着细节）
+ [体型/情绪/气质]（骨架+构图/镜头+动作/视线+氛围词）
```

### 5. 编辑公式（四要素）
```
[标注工具与方位]（红框内/沿红色箭头/地标点处/红线左侧）
+ [具体修改对象] + [动作与变化描述] + [生效时序]（全片统一/特定秒段/逐渐显现）
```

### 6. 转场公式（三段式）
```
[转场类型指引] + [基础约束要求] + [切镜逻辑要求]
必带："禁止生硬切镜、禁止物体凭空出现"
可加"景别由 C 转变为 D"；多转场自选写法："请从[自然切换/遮罩/水墨/相似物]中根据本片风格选择最合适的一种"
```

### 7. 白模公式（两粒度）
```
粗颗粒 = 【参考声明】（"参考[视频1]的{运镜|动作|动线|光影变化|角色站位|音乐音效|画面节奏}"）
       + 【对应关系映射】（"将[视频1]中的{颜色/形状特征}模型替换为[图X]的{角色名}"）
       + 【剧情详述】+【场景处理】+【整体收束】
细颗粒 = 【渲染指令】（"将[视频1]的白模动画渲染成最终成片"）+【分段渲染描述】+【场景处理】+【整体收束】
```

### 8. 多宫格分镜公式
```
说明每格含义（人物/场景/完整镜头）→ 主体设定（引用参考图详述）→ 按故事梗概逐镜补齐（构图/景别/运镜/动作）→ 全局风格与禁止项
```

## 二、时间戳文本控制（2.5 核心新特性）

**语法四种，帧数+秒数双写最稳**（24fps 验证准确）：

| 语法 | 写法 |
|------|------|
| 秒段式 | `0s-3s：…` / `0-3s｜第一阶段【追问】` |
| 时间码式 | `[00:00 - 00:07]`、`[00.0-05.0s]` |
| 帧数式 | `第 0–90 帧 (0s - 3s)` |
| 双写（最稳） | `第 660–720 帧 (22s - 24s)` |

**每段时间切片四层**：

```
[起-止秒数]+[核心阶段/主题]      → 如 "0-3 秒【追问】—— 不甘的等待"
[动作/表情物理指令]              → 景别+构图+细节动作
[情感解析/镜头调度潜台词]        → 向 AI 解释物理指令的深层表达（官方明确这是"导戏"关键）
[其他要求]                       → 转场/音频卡点
```

**用途**：多镜头剧情防"快进"、卡点/MV（"第 158 帧镜头切面部特写"）、广告分阶段（前 5s 外观/中 10s 功能/后 5s 效果）、高级编辑生效时序（"1–8 秒把牛仔裤替换为黑西装裤"）。

## 三、@引用系统（2.5）

- 语法：`@图1`/`@图片1`/`@图片一`/`@视频1`/`@音频1`/`@音效2`/`@参考图1-@参考图5`（范围引用）
- 编号按上传顺序，图/视频/音频各自独立编号
- **每个引用必须标明用途**：人物[面孔/特征]一致性、音色、动作、场景、道具、背景、[构图/白模/空间关系]一致
- 可多次引用（180s 案例 12 图全程 @；白模案例 13 图+2 视频+1 音频）
- 音频两用法：BGM（"背景音乐请使用@音频1"）+ 音色（台词后挂"音色参考@音频1/2/3/4"，多人各配音色）
- 无缝转场："将【@视频1】和【@视频2】无缝衔接起来，但是不修改【@视频1】和【@视频2】"

## 四、12 条可判定规则（质量门）

（SKILL.md 质量门章节为正式条目，此处为规则原文速查）

| # | 规则 | 核心谓词 |
|---|------|---------|
| 1 | @引用完整性 | 每个 @ 引用紧跟用途标注；素材按上传顺序编号 |
| 2 | 时间戳覆盖律 | 闭区间、按时间顺序、首段 0s 起、末段覆盖全时长、段间连续 |
| 3 | 时长档位律 | >30s 走超长模式；延长仅对 ≤30s 产物、单次 4-30s、累计 ≤60s |
| 4 | 延长必填词 | 含"向前/向后延长、延续、续写"类动词 + 仅描述新增时段 |
| 5 | 转场三段式 | 齐三段 + 含"禁止生硬切镜、禁止物体凭空出现" |
| 6 | 真人公式覆盖 | 7 维至少 4-5 维（含保真后缀、面部特征 ≥3 点） |
| 7 | 禁止项四维 | 声音+字幕+行为+崩坏高发处各 ≥1 项 |
| 8 | 编辑四要素 | 标注工具与方位+修改对象+变化描述+生效时序 |
| 9 | 白模映射律 | 粗颗粒有对应关系映射；细颗粒以渲染指令开头 |
| 10 | 无缝转场三要素 | 不修改声明+衔接延续描述+形状/位置/大小/运动方向一致 |
| 11 | 30 秒结构律 | 总述+全局设定（含表演核心与禁止项）+时间戳分镜（含潜台词）三层 |
| 12 | 静音约束 | 逐项写（无BGM/静音/无旁白/无环境杂音），不笼统 |

## 五、平台限制与参数（2.5）

| 项 | 2.5 规格 |
|----|---------|
| 输入图片 | ≤30 张，单张 <30MB（jpeg/png/webp/bmp/tiff/gif/heic/heif），请求体 <64MB 勿用 Base64 |
| 输入视频 | ≤10 段，单段 2-30s，总 ≤30s |
| 输入音频 | ≤10 段，总 ≤30s；支持仅音频输入 |
| 输出时长 | 4-30s；超长模式 30-180s；延长累计 ≤60s |
| 分辨率 | 480p/720p（网页端 720P+） |
| 帧率 | 输出 24fps 基准（帧数指令按 24fps 换算） |
| 模式 | 全能参考 / 智能编辑 / 超长视频 / 首尾帧 |
| 稳定性阈值 | 主体音视频 1-5 好（6-10 可尝试）；主体 5-10s 好；主体图 1-8 好（9-12 可尝试）；>5 主体单视图更稳（多视角拆多图）；编辑输入 ≤20s 好 |

## 六、已知失败模式与避坑（2.5）

- 延长仅对 ≤30s 底片有效
- 粗颗粒白模忌四肢/翅膀模型（动作僵化，须写完整动作序列）
- 细颗粒白模上传视频需去除轨迹线/坐标线/camera cone
- 2.0 遗留：消除留残影、绿幕泛绿、BGM 删不净；2.5 偶发物理逻辑瑕疵（"结尾帽子掉落毫无征兆"）——属模型边界，记 director-log 的 acceptable_limitation
- 版权规避显式写；儿童内容禁 IP/logo/商标/水印
- **潜台词/情感解析层不可省**——纯物理指令易被机械执行

## 七、官方表演雏形与 07 表演层的衔接

| 官方雏形 | 07 方法论化位置 |
|---------|----------------|
| 表演核心行（"克制细腻。重点呈现眼神流转、呼吸起伏、唇部微颤……"） | performance-direction.md §4 表演核心行公式 |
| 时间戳分镜第三层情感解析（"笑意刚到嘴角……仿佛要强行把委屈咽回肚子里"） | performance-direction.md §2.4 潜台词层 + §5 节拍系统 |
| 真人公式 [眼神/灵魂][体型/情绪/气质] | performance-direction.md §1 角色内在 |

**官方缺口（07 补全处）**：
1. 微表情时序的系统化——官方是案例级零散 → 词汇库 + 节拍系统
2. 否定约束的语法与力度分级——官方禁止项零散 → negative-constraints.md
3. 表演心理学（内心变化轨迹/情绪实质/时间窗口）——官方完全没有 → performance-direction.md §2
