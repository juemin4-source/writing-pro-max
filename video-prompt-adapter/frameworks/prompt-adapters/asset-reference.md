# Asset Reference — 资产引用锚定模式

## Purpose

把"一致性"从口头要求变成**可判定的引用锚定**。对应 03/05 管线 continuity-locks 在平台上的落地方式：一份提示词里，所有"必须是同一个"的东西都用可识别的引用 + 用途标注钉死。

## 两种锚定形态

| 形态 | 平台 | 语法 | 一致性锁的对应 |
|------|------|------|---------------|
| @ 引用锚定 | Seedance 2.5 | `@图片1 的人物[面孔/特征]一致性` | character / propState / scene locks |
| 资产 ID 锚定 | pippit 型平台 | `<role data-material-pippit-asset-id="…">R8</role>` + `<duration-ms>` | 资产 ID 直接入文，机器可解 |

## 一、@ 引用锚定（Seedance 2.5）

### 命名与编号
- `@图片1-@图片30` / `@视频1-@视频10` / `@音频1-@音频10`（2.5 上限）
- 编号 = 上传顺序；图/视频/音频各自独立编号
- 范围引用：`@参考图1-@参考图5`

### 每个引用必须标明用途（官方硬要求）

| 用途 | 写法 |
|------|------|
| 人物面孔/特征 | `@图片1 的人物[面孔/特征]一致性` |
| 构图/白模/空间关系 | `保持@图片2 的[构图/白模/空间关系]一致` |
| 场景/背景 | `场景参考@图片3` |
| 道具 | `手持@图片4 的武器` |
| 服装 | `穿着@图片5 的服装` |
| 运镜 | `参考@视频1 的运镜效果` |
| 动作 | `参考@视频2 的动作编排` |
| 音色 | `音色参考@音频1`（挂在台词后，多人各配音色） |
| BGM | `背景音乐请使用@音频1` |
| 音效 | `环境与动作音效使用@音效2、@音效3` |
| 字体/文字 | `字体参考@图片2 的字体` |
| 风格/质感 | `整体风格参考@参考图1-@参考图5` |

### 锁定语法（一致性最强级）
```
基于上传的[图片]，严格保持@图1 的人物[面孔/特征]一致性，保持@图2 的[构图/白模/空间关系]一致，
严格锁定人物站位。全文的 prompt 中多次 @ 图/视频/音频，会更加准确。
```

### 多引用组合规则
1. 公共素材用固定编号（角色从 @图片1 起，视频 @视频1，音频 @音频1）
2. 版本独立素材在公共编号后递增
3. 每个素材标题后标注 @ 编号，方便对照上传
4. 引用是"参考/锚定"还是"编辑/修改"要写清（参考 = 借鉴风格动作；编辑 = 在原素材上改）

## 二、资产 ID 锚定（pippit 型平台）

平台用结构标签把资产 ID 嵌入提示词，模型按 ID 精确取用素材：

```html
本片段场景设定在: <location data-material-pippit-asset-id="ASSET_0001">L1</location>
分镜2: 中景，手持拍摄<role data-material-pippit-asset-id="ASSET_0002">R3</role> 站在柜台前整理单据。
分镜1<duration-ms>4000</duration-ms>: …（显式时长锚定）
```

要点：
- `location` / `role` 标签携带 `asset-id`，角色与场景身份由 ID 决定，不靠长相描述——**这就是换脸问题的平台级解法**
- `duration-ms` 显式时长锚定每个分镜
- 参考图也以 ID 锚定：`分镜1 的参考图是<pippit-asset-id …>ASSET_0003</pippit-asset-id>`（ID 用实际资产编号替换）

适配动作：本管线的 asset 编号（C001/EP04-S05 等）在转写时映射为平台 ID；映射表随提示词交付。

## 三、与 continuity-locks 的对接映射

| continuity-locks 字段（03/05） | 07 锚定写法 |
|-------------------------------|------------|
| `character: [C001_晨·正面]` | `@图片1 的人物[面孔/特征]一致性`（+ 人设段锚点逐项） |
| `propState: [照片·边角微卷]` | 道具状态入画面描述：`桌上的照片边角微卷`（保持状态一致） |
| `scene: [EP04-S05 场景]` | `场景参考@图片3` 或 `asset-id` location 标签 |
| `costume: [深灰工装·袖口磨毛]` | 服装锁在人物造型段 + `穿着@图片5 的服装` |
| 站位/动线 | `严格锁定人物站位` + 空间交互描述 |

## 四、音频锚定（两个用途要分开写）

```
BGM："背景音乐请使用@音频1"
音色："…说：'台词'，音色参考@音频2"（多人各配音色时：@音频1/2/3/4 逐个挂）
音效："环境与动作音效使用@音效3"
```

## 五、检查清单

- [ ] 每个 @ 引用都有用途标注（无裸引用）
- [ ] 角色一致性引用带 `[面孔/特征]` 明确维度
- [ ] 多人戏每个角色独立锚定，无共用引用
- [ ] 道具/服装状态与 continuity-locks 一致
- [ ] pippit 型：location/role/asset-id/duration-ms 齐全
- [ ] 编号与上传顺序一致，无跳号、无复用
