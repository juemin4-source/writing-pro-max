# Seedance 2.5 平台适配细则

> 公式 + 示例的实操层。公式来自官方 2.5 手册；示例为方法论演示（自创场景，非任何用户样本）；表演层注入点标注 🎭。与 seedance-official-format.md（格式总纲）、performance-direction.md（表演层）配套。

## 适配总则

1. **公式保形**：八套公式的必填词一个不省（见 seedance-official-format.md §一）
2. **表演注入**：公式里凡是"表演核心""情感解析""人物造型"的位置，就是表演层入口
3. **时长先定**：先定档位再选公式（4-8s 基础 / 9-30s 时间戳 / 延长 / 超长）
4. **禁止项殿后**：结尾全局补充段放禁止项（四维 + 静音逐项）

## 时长档位适配

| 档位 | 公式选型 | 表演密度 |
|------|---------|---------|
| 4-8s | 基础公式 | 1 个完整动作节拍（日常态→触发→变化），表演核心行一句 |
| 9-15s | 基础公式 + 时间戳分镜 2-4 段 | 每段 1 个微表演 + 潜台词 |
| 15-30s | 30 秒三层公式 | 表演核心行 + 分镜每段节拍 |
| 30-60s | 延长拼接 | 衔接点表演状态 = 上段结尾 = 下段开始 |
| 60-180s | 超长公式 | 全局设定段写表演核心行；分镜逐段节拍 |

## 1. 基础生成（4-30s）

```
【素材描述】@图片1 的人物[面孔/特征]一致性；@图片2 场景参考
【一句话概述】主体 + 地点 + 事件 + 题材/风格 + 特殊运镜
【具体情节描述】分时间轴：[秒段] 画面+运镜+动作+台词+音效；反向：不要字幕/BGM
【全局补充】贯穿元素 + 全局禁止项
```

🎭 表演注入点：具体情节描述的"动作"里放微表演指令 + 潜台词。

## 2. 真人人物（7 维公式）

```
[年龄/种族] 32 岁东亚男性，棱角分明但疲惫的都市脸
[肤色/皮肤质感] 暖调小麦色，带有风霜感与细微干纹，保留真实的微细毛孔与肌肤纹理
[面部细节特征] 深眼窝，眉骨突出，鼻梁高挺克制，下颌线利落，颧骨处有一道旧疤
[眼神/灵魂] 眼神疲惫而安静，目光落在虚空处，透着一层压了很久的倦
[发型/发色] 黑灰色短发，发丝干枯，有几缕被风搅乱
[服装/服装质感] 洗到发白的深灰工装外套，袖口磨毛，领口微敞
[体型/情绪/气质] 肩背微驼，中近景构图，视线低垂，整体散发着被生活磨平棱角的钝感
```

必填：保真后缀（毛孔/肌肤纹理）不可省；面部特征 ≥3 点；7 维至少 4-5 维。

## 3. 30 秒长视频（三层公式）🎭 表演核心行 + 潜台词是第三层的硬要求

```
总述名称：30 秒一镜到底（深夜小吃店老板娘）
【多模态参考层】基于上传的图片，严格保持@图1 的人物[面孔/特征]一致性，严格锁定人物站位
【全局设定】
基础环境与质感：凌晨一点的老城巷口小吃店，蒸汽与油烟混着昏黄灯光。强调极致的真实物理质感。
视觉风格：电影感，浅景深，暖黄橙色调，低饱和，中低反差，轻微胶片质感。
镜头语言：始终保持在老板娘的中近景，轻微手持呼吸感，无快速剪辑。
人物造型：[真人 7 维公式，见上节]
表演核心：克制细腻。重点呈现眼神停顿、手部动作中段、呼吸变化、嘴角牵起短促的笑旋即落下的过程。
禁止项：禁止夸张哭腔，禁止快速剪辑，禁止大幅度肢体动作，禁止生成多余台词或 BGM，禁止字幕。
【时间戳剧本分镜】
第一阶段 0-6 秒【空荡】：她低头擦桌，动作机械。手在桌面来回抹过三遍。
　（情感解析：不是勤快，是心里有事，用重复动作压住情绪）
第二阶段 6-12 秒【来电】：手机亮起，她看了一眼屏幕，手上的抹布停在桌沿，没有接。
　（情感解析：她认得那个号码，但不确定该不该接——停顿的长度就是犹豫的深度）
第三阶段 12-20 秒【回拨】：她抿嘴，拨回去，电话接通瞬间，她开口第一句声音发颤。
　（情感解析：白天攒的硬气，在听到对方声音的那一刻就塌了）
第四阶段 20-30 秒【落座】：她挂了电话，慢慢坐下，安静了几秒，然后继续擦那张已经擦了三遍的桌子。
　（情感解析：生活没有给她演哭戏的时间，擦桌子就是她的消化方式）
```

## 4. 超长视频（60-180s）

```
【全局参数】视频时长 90 秒，画幅 16:9，电影级写实画质
【素材描述】@图1-@图5 角色/场景逐一标注用途
【一句话概述】…
【具体情节描述】0-10s / 10-20s / …（故事线或时间轴，每段含动作+台词+音效+反向项）
【全局补充】贯穿元素 + 禁止项
```

要点：素材@清楚 + 故事描述清楚；长时序一致性靠角色设定字段全片复用（同一段人物造型在分镜里不重复抄，但首次出现处写全）。

## 5. 视频延长

```
必填动词 + 仅描述新增时段 + 衔接约束：
"参考@视频1 的内容，延长视频 5s 向后延长。要求延长自然、动作衔接流畅、动作衔接自然，
禁止生硬切镜、禁止物体凭空出现。[新增时段画面描述]"
```

切镜式延长 = 转场三段式（转场类型指引 + 基础约束 + 切镜逻辑 + "景别由 C 转变为 D"）。

## 6. 智能编辑 / 高级编辑

```
智能编辑：[具体修改对象] + [动作与变化描述] + [生效时序]
　例："把整个视频 0-5 秒的白色背景，全部变成绿幕背景。去掉声音，保持静音。"
高级编辑（带标注）：「标注工具与方位」+「修改对象」+「变化描述」+「生效时序」
　例："将红框内的沙发区域，生成一个白模女生，白模女生正在看电视。"
BGM 分离："去除@视频1 中的背景音乐，保留清晰的人声。画面、字幕、画质、色调、构图全部保持不变。"
```

## 7. 转场（三段式）

```
基础：需要在切镜处使用"[自然镜头切换/遮罩/水墨/相似物/动作/动态接力…]"转场（禁止生硬切镜、禁止物体凭空出现）
约束：保持镜头呼吸感与时长协调；镜头 A [内容]，自然过渡到镜头 B [内容]
逻辑：要求必须自然切换场景。并且景别由 C 转变为 D。
多选一："请从 [自然切换/遮罩/水墨/相似物] 等转场方式中，根据本片风格选择最合适的一种"
```

## 8. 白模

```
粗颗粒：【参考声明】参考[视频1]的{运镜|动作|动线|光影变化|角色站位|音乐音效|画面节奏}
　　【对应关系映射】将[视频1]中的{白色人型}模型替换为[图X]的{角色名}
　　【剧情详述】【场景处理】【整体收束】
细颗粒：以"将[视频1]的白模动画渲染成最终成片"开头 + 分段渲染描述 + 场景处理 + 收束
```

避坑：粗颗粒忌四肢/翅膀模型（须写完整动作序列）；细颗粒上传视频去轨迹线/相机锥。

## 9. 多宫格分镜

```
[图1]为完整电影分镜脚本，共 N 个连续镜头，每个分镜代表一个完整镜头。
[主体设定]：角色参考[图2]三视图，[真人/角色 7 维描述，全片一致]
镜头 1（0-3s）[景别/机位/运镜 + 动作 + 台词的逐镜补齐]
…
全局风格与禁止项
```

## 10. 音色参考 / 多人参考

```
音色："…说：'[台词]'，音色参考@音频1，保持[低沉/哽咽/含混]的语调"
多人："人物 A 与人物 B 正坐在篝火旁交谈，人物 A 递给人物 B 一杯水"——
每个角色独立 @ 锚定 + 空间交互描述 + "不串脸、不换装、身份各自贯穿"
```

## 11. 无缝转场（两视频拼接）

```
"将【@视频1】和【@视频2】无缝衔接起来，但是不修改【@视频1】和【@视频2】。
[衔接元素延续描述：形状/位置/大小/运动方向一致]。不要改变上传的两个视频。"
```

## 12. 空间视角修改 / 局部消除

```
"将@视频1 的多机位切换镜头替换成正面视角的固定镜头，并保持人物和背景不变"
"将@视频1 里左边的女子和右边的男子消除掉，只留下中间的女子，动作保持不变"（局部消除：补全背景描述）
```

## 13. 迁移创意

```
"请参考@视频1 的[创意形式/镜头节奏/转场方式/深层情绪]，[新主体]……描述想要迁移内容的内核
（如可爱状态、喜剧效果、镜头语言）"
```

## 示例自查清单

- [ ] 必填词齐全（对应公式）
- [ ] 每个 @ 引用带用途
- [ ] >8s 有时间戳且四层齐全（含潜台词）
- [ ] 表演核心行在全局设定段（含人物时）
- [ ] 禁止项四维 + 静音逐项
- [ ] 时长档位正确
