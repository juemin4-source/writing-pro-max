# Performance Direction — 表演层方法论

## Purpose

把「人物在演什么、怎么演、演到什么程度」写成提示词里的可执行指令。官方 Seedance 2.5 手册的表演是案例级雏形（表演核心行、时间戳分镜的情感解析层）；本文件将其系统化为六件套方法论。来源：用户实战标准（2026-08-01 黄金样本的提炼，不逐字复制）+ 官方表演雏形 + 表演学常识。

## 六件套总览

| # | 件 | 回答的问题 | 对应 |
|---|----|-----------|------|
| 1 | 角色内在 | 这个人是谁、用什么尺度演 | B1 |
| 2 | 表演心理学 | 此刻内心怎么变、为什么变 | B2 |
| 3 | 微表演指令 | 具体演哪些可见细节 | B3 |
| 4 | 否定约束 | 不准演成什么样 | B4 → negative-constraints.md |
| 5 | 风格体系 | 画面用什么调色/光位语言 | B5 |
| 6 | 镜头-关系 | 机位替谁说话 | B6 |

## 1. 角色内在（人设段 · B1）

三个子块，每块一句话到两句话，全部放提示词开头附近（人物第一次出现处）。

### 1.1 性格气质
一句话定性人物底色。用"形容词 + 气质名词"结构，避免空泛的"善良/美丽"：

```
模板：[两三个性格形容词]，[气质名词]型人物
示例：现实题材基层青年，沉稳、寡言、有分寸感，收着演的气质
```

### 1.2 表演基调
规定情绪表达**尺度与方式**——告诉模型这套戏的表演温度：

```
模板：情绪表达[偏细腻/偏内敛/热烈外放]，不[夸张/外放/表情包式演法]
示例：情绪走内敛路线，细微处给戏，不做大幅度的夸张反应
```

基调词汇表（可选）：

| 基调 | 适用 | 配套写法 |
|------|------|---------|
| 克制细腻 | 现实题材/正剧 | 重点写微表情，禁大动作大情绪 |
| 冷面暗涌 | 强冲突/对峙 | 表面无表情，手部/呼吸泄露内心 |
| 松弛生活化 | 日常/治愈 | 动作不设计，保留下意识小动作 |
| 收放分明 | 短剧/强情节 | 平时收敛，触发点一次性放出 |
| 浮夸表演型 | 喜剧/动画 | 允许夸张，但写明"幅度递增" |

### 1.3 一致性锚点
逐项列出不可漂移的特征——这是"同一个人的保证书"：

```
模板：保持[脸型]、[五官比例]、[年龄感]、[发型结构]、[整体气质]一致
示例：保持同一个人——脸型、五官比例、年龄感、发型结构和整体气质全部一致，不换脸，不漂移
```

锚点应引用资产：有角色卡/参考图时改写成 `@图片N 的人物[面孔/特征]一致性`（见 asset-reference.md）。

## 2. 表演心理学（过程感与潜台词 · B2）

**核心原则：表演不是单一情绪，而是"过程感"和"潜台词"。** AI 模型缺的不是情绪词汇，而是情绪**变化的过程**与变化**的原因**。

### 2.1 内心轨迹三段式

```
① 日常态（演的是"平时"）：礼貌应对/专注做事/松弛待着
② 触发点（演的是"刺激"）：听到一句话 / 看到一个消息 / 面对一个人
③ 内心变化（演的是"变"）：轻微但明确的内心波动 + 外部可见的对应物
```

写法模板：

```
人物先处于[日常态]。在[触发点]之后，内心发生[变化方向]。重点表现[微表演载体]。
```

示例（方法论级，非样本原文）：
> 面馆老板娘先处于忙碌的日常状态，在接到一通电话之后，手里的抹布停在桌沿上，内心从平静变成说不清的慌乱。重点表现眼神停顿、手部动作中段、呼吸变浅。

### 2.2 情绪实质（是什么 + 不是什么）

模型分不清"羞"和"摆拍羞"——所以把情绪的**心理实质**写清楚：

```
模板：[这个情绪是什么]——不是[常见误解/摆拍版本]，而是[现实的心理实质]
示例：不是应酬式的礼貌微笑，而是自己都没料到的、压不住的欢喜
```

心理实质的常见写法维度：

| 维度 | 示例写法 |
|------|---------|
| 程度 | "不是夸张的 X，而是很真实的 Y" |
| 内在矛盾 | "心里有波动甚至有点甜，但更多是局促" |
| 延迟反应 | "先是懵，然后才反应过来" |
| 未完成态 | "像不知道该怎么回应" |

### 2.3 时间窗口

表演要**精确到几秒钟**——"刚发生的那几秒"与"事情过去后的反应"完全不同：

```
模板：重点表现[精确时间窗口]——[窗口内发生什么]
示例：重点表现消息落定的那几秒钟——先是没反应过来，然后情绪才追上来
```

### 2.4 潜台词层（向 AI 解释物理指令）

官方时间戳分镜的第三层（情感解析）方法论化：

```
每个物理动作指令后，补一句"为什么这么演"：
[动作/表情物理指令] +（情感：这句解释动作承载的潜台词）
```

示例：
> 视线移开望向别处——（情感：不是生气，是不知道该怎么回应，下意识想逃开这个注视）

**潜台词层不可省**：纯物理指令会被机械执行（官方原话精神）。

## 3. 微表演词汇库（指令级 · B3 扩充）

七类。每个词是**可拍摄的可见细节**；用时给动作加**力度词**（轻微/极轻/几乎难以察觉/明显/骤然），给情绪加**方向词**（慌/怕/甜/冷）。来源：用户标准与官方雏形提炼，示例句为方法论组合。

### 3.1 眼神（信息量最大的微表演载体）

| 词汇 | 用法提示 | 潜台词方向 |
|------|---------|-----------|
| 眼神停顿 | 视线落点固定半秒以上 | 愣住/辨认/决定 |
| 视线偏移 | 缓慢或快速移开落点 | 躲闪/心虚/不舍 |
| 眼神躲闪 | 反复不敢对焦 | 羞/怯/撒谎 |
| 不敢长时间看对方 | 每次对视 <1 秒即移开 | 心动/自卑 |
| 眼神决绝 | 目光钉死不动 | 下定决心 |
| 瞳孔涣散 | 焦点失焦、看而不见 | 崩溃/走神/创伤 |
| 目光低垂 | 看向地面/桌面 | 沉默/认命/回避 |
| 眼神颤动 | 目光微抖 | 忍住情绪 |
| 眼神一秒降温 | 温度骤降 | 翻脸/被冒犯 |

示例句：*他抬眼看向她，眼神停了一拍，然后迅速移开，落在杯沿上。*

### 3.2 面部

| 词汇 | 用法提示 | 潜台词方向 |
|------|---------|-----------|
| 嘴角控制不住地上扬 | 想压住但压不住 | 开心但不好意思 |
| 嘴角牵起短促的笑旋即落下 | 笑只存在半秒 | 自嘲/苦笑/认命 |
| 冷漠笑意 | 只有嘴角动，眼不动 | 敌意/轻蔑 |
| 抿嘴 | 上下唇收紧 | 忍住/紧张 |
| 下颌收紧 | 咬肌微动 | 忍怒/忍泪 |
| 嘴唇微颤 | 幅度极小 | 强忍/欲言又止 |
| 嘴唇微启又合上 | 想说话又停住 | 欲言又止 |
| 眉心蹙起/慢慢松开 | 眉头变化过程 | 疑惑→释然 |
| 鼻翼轻微收缩 | 极微 | 吸鼻/强压情绪 |
| 眼眶泛红但眼泪被屏住 | 红而不落 | 忍住哭 |

示例句：*她嘴角先向上弯了一下，又迅速压平，只有鼻翼轻轻收缩了一下。*

### 3.3 呼吸与生理

| 词汇 | 用法提示 | 潜台词方向 |
|------|---------|-----------|
| 呼吸停顿半拍 | 吸气中断 | 惊吓/顿悟 |
| 胸口轻轻起伏一次 | 刻意压住的深呼吸 | 强装镇定 |
| 呼吸变急 | 频率上升 | 紧张/激动 |
| 剧烈喘息 | 幅度大、带声 | 精疲力竭/崩溃 |
| 额头冷汗 | 光线下可见 | 恐惧/高烧/压力 |
| 汗水顺着脸颊滑落 | 特写可用 | 体力透支 |
| 指节发白 | 握紧导致 | 忍怒/用力 |

### 3.4 手部（最容易被 AI 演成"手无处安放"的部位）

| 词汇 | 用法提示 | 潜台词方向 |
|------|---------|-----------|
| 手指碰杯子/餐具/纸巾 | 无意识的接触物 | 紧张/转移注意力 |
| 无意识地摸口袋 | 重复动作 | 确认/不安/习惯 |
| 手部小动作 | 整理衣角/搓手指 | 手足无措 |
| 手指停在半空 | 动作中段 | 被打断/愣住 |
| 攥紧又松开 | 循环 | 犹豫/挣扎 |

### 3.5 身体与姿态

| 词汇 | 用法提示 | 潜台词方向 |
|------|---------|-----------|
| 身体有点紧 | 肩背僵硬 | 局促/防御 |
| 肩膀轻微收紧/放松 | 变化过程 | 警觉→释然 |
| 双膝一软 | 单膝或双膝失去支撑 | 体力崩溃/绝望 |
| 步子变慢/变轻 | 步态变化 | 迟疑/靠近 |
| 顿住 | 全身定格 | 惊讶/被击中 |
| 动作中段 | 动作做一半停住 | 变化发生 |
| 缓缓转身/缓缓抬头 | 用"缓缓"压速度 | 郑重/艰难 |

### 3.6 时间与节拍（表演的"拍点"）

| 词汇 | 用法提示 |
|------|---------|
| 看了 X 秒 | 明确注视时长，"看了足足三秒" |
| 表情从 A 到 B 再到 C | 变化序列："从冷漠到惊讶再到平静" |
| X 秒的死寂停顿 | 无声段："0.5 秒的死寂停顿" |
| 动作先……然后……最后…… | 三步递进 |
| 眼泪没有预兆地掉下来 | 强调无准备感 |

### 3.7 声音表演（对白外的声音指令）

| 词汇 | 用法提示 |
|------|---------|
| 声音发颤 | 语尾抖 |
| 声音极低 | 压到几乎听不见 |
| 声音嘶哑 | 带颗粒感 |
| 声音从激动到含混 | 情绪走向：音量/清晰度变化 |
| 轻声低语 | 气声 |
| 停顿后再说 | 字与字之间的留白 |
| 声音渐弱 | 话语被自己咽回去 |

示例句：*他第一句说得又急又响，第二句突然低下去，最后几个字几乎含混在喉咙里。*

## 4. 表演核心行（官方雏形方法论化）

官方 30 秒公式的"表演核心"字段是用户微表演清单的简化版。方法论：

```
公式：表演核心：[基调词]。重点呈现[3-6 个微表演动作的清单]。[禁过度项]
```

| 要素 | 官方雏形示例（手册原文） | 方法论化写法 |
|------|------------------------|-------------|
| 基调词 | 克制细腻 | 与角色内在的表演基调保持一致 |
| 动作清单 | 眼神流转、呼吸起伏、唇部微颤、眉心松紧、鼻翼变化、喉头吞咽及眼泪自然滑落 | 3-6 个，来自词汇库，按"发生顺序"排列 |
| 禁过度项 | 禁止夸张哭腔、禁止眼泪提前滴落 | 时序性否定（见 negative-constraints.md §时间限定） |

**表演核心行放在全局设定段**（30 秒公式模块二），时间戳分镜里再按段展开。

## 5. 表演节拍系统（时间戳里的表演）

长视频（>8s）的表演按节拍写。每段时间切片四层（官方公式 + 表演方法论）：

```
[起-止秒数]+[核心阶段/主题]         ← 表演阶段命名（追问/认命/放手…）
[动作/表情物理指令]                 ← 景别+构图+微表演细节
[情感解析/潜台词]                   ← 为什么这么演（2.4 节）
[其他要求]                          ← 转场/音频卡点/时间限定
```

带节拍的表演 = 给变化序列定**时长与顺序**：

```
[00:00-00:03] 日常态：低头看手机，无表情
[00:03-00:06] 触发：抬头看见对方，眼神停顿，笑容顿住
[00:06-00:09] 变化：嘴角慢慢压平，目光移开，手指捏紧衣角
[00:09-00:12] 落定：深吸一口气，肩膀放平，重新看向对方
```

**节拍命名**用情绪动词（追问/认命/记住/惋惜/放手），每段一句话给模型锚定阶段感。

## 6. 镜头-关系逻辑（B6）

机位语义表——镜头为什么这么摆：

| 机位/角度 | 叙事语义 | 示例写法 |
|----------|---------|---------|
| 过肩镜头 | 关系/权力/连接 | "从 A 的过肩视角拍 B"——A 在审视/保护 B |
| 下方仰视 | 压迫/神性/仰视 | "从下方仰视拍摄"——主体显高大 |
| 高处俯视 | 支配/评判/无助 | "从上方俯拍"——主体显弱小 |
| 固定镜头 | 克制/旁观/纪实 | 固定=观察者不介入 |
| 手持 | 在场/主观/慌乱 | 轻微手持=呼吸感 |
| 主观视角 | 代入 | POV=观众就是角色 |
| 带关系入画 | 让关系成立 | "中近景，带一点画外对手的肩膀或背影" |

写法原则：

1. **镜头语义要写出来**："从她的过肩视角"比"中景"信息量大
2. **构图为关系服务**：双人戏优先交代空间关系（谁在画内/画外、谁高谁低）
3. **固定镜头配微表演**：固定机位 + 微表情 = 表演聚焦；运动镜头表演会被稀释

## 7. 风格体系参数化（B5）

调色写成**可替换的参数块**，放全局设定段：

```
模板：统一[基调色]调色。高光偏[高光色]，阴影略带[阴影色]，[饱和度]，[反差]，[质感词]
示例：统一暖黄橙调色，高光偏暖黄橙，阴影略带灰蓝，低饱和，中低反差，轻微胶片质感
```

内置体系模板（可扩展）：

| 体系 | 基调 | 高光 | 阴影 | 饱和度/反差 | 质感 |
|------|------|------|------|------------|------|
| 现实生活 | 暖黄橙 | 暖黄橙 | 灰蓝 | 低饱和/中低反差 | 胶片 |
| 科幻冷调 | 冷灰蓝白 | 冷白 | 深蓝黑 | 低饱和/高反差 | 冷硬干净 |
| 赛博霓虹 | 暗部黑+霓虹高饱和色 | 霓虹（粉/青） | 墨黑 | 高饱和/高反差 | 玻璃反光 |
| 水墨国风 | 纸白墨黑 | 纸白 | 墨灰 | 低饱和/中反差 | 墨染 |
| 童话治愈 | 奶油暖白 | 暖白 | 浅棕 | 中高饱和/低反差 | 柔和磨砂 |

与 04 的对接：体系模板可映射到五行色彩（现实生活 ≈ 木基调 organic-natural；赛博霓虹 ≈ 水基调 neon-fluid；废土 ≈ 土基调 heavy-realism）；光位用 04 lighting.md 词汇（伦勃朗/边缘光/窗口光/实用光）；焦段用 04 lens.md（35mm 标准纪实 / 85mm+ 长焦孤独隔离）。

## 8. 组装模板（表演层完整段落）

单镜头表演层段落：

```
【角色内在】[性格气质]。情绪表达[表演基调]。保持[一致性锚点]一致，不换脸不漂移。
【表演】人物先[日常态]，在[触发点]之后，内心[变化方向]。[时间窗口]内，重点表现[微表演清单]。
　——[潜台词：为什么这么演]
【镜头】[景别+机位语义]，[构图为关系服务]。
【风格】[调色参数块]，[光位]，[焦段]。
【否定】[按题材选配 negative-constraints.md]
```

时间戳分镜内的表演段（>8s）：

```
[00:00-00:XX] [阶段命名]：动作/表情物理指令 +（情感解析：潜台词）+ [其他要求]
```

## 9. 导演判定标注

本文件的方法论判断性很强，SKILL.md 质量门的表演层清单（四条）逐条过：

| 检查项 | 机械可查 | 导演判定 |
|--------|---------|---------|
| 人设段三子块齐全 | ✅ 字段存在 | 气质定性是否准确 |
| 心理学三段式完整 | ✅ 三段都有 | 轨迹是否符合人物 |
| 微表演指令可见可拍 | ✅ 无不可拍词 | 表演密度是否合适 |
| 潜台词层存在 | ✅ 有"（情感：…）" | 潜台词是否解释到位 |
| 风格参数块完整 | ✅ 五参数齐全 | 体系选择是否贴合题材 |
| 镜头有语义 | ✅ 机位词存在 | 关系语义是否导演意图 |
