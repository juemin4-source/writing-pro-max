# Seedance Platform Spec

## 基础参数

| 参数 | Seedance 2.0 |
|------|-------------|
| 视频长度 | 5秒 / 10秒 / 15秒 |
| 分辨率 | 1080p (1920×1080), 4K (3840×2160) |
| 帧率 | 24fps, 30fps |
| 输出格式 | MP4, MOV |
| 画幅 | 16:9 (横屏), 9:16 (竖屏), 1:1 |
| 参考图 | 支持 1-4 张图片参考 |
| 角色一致性 | 支持固定角色形象 |

## 提示词限制

- 中英文混合，优先中文
- 总长度 ≤ 500 字符
- 参考素材需先上传到素材库
- 运镜指令放在提示词开头效果最好
- 负面提示词暂不支持

## 多模态引用系统

```
@image(id)    参考图片风格/构图
@video(id)    参考视频运镜/节奏
@audio(id)    参考音频对齐节奏
@character(id) 统一角色外观
```

## 已知限制

- 复杂多人互动效果不稳定
- 快速运镜可能导致画面模糊
- 文字渲染不精确
- 超长视频需分段生成
