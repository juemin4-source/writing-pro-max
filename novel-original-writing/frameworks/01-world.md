# 01 — 世界生成期（B 阶段操作细则）

> **理论来源**：麻雀世界观方法论出自用户自著《人物篇》第一章「先写一个麻雀世界观」（尺度问题/麻雀世界观）；历史压力与推导七步综合自《人物篇》第二章「故事位置」（机制受力点）与《命运篇》（世界缺憾 → 人物受压的对应关系）。余震段标注出自《文学天演论》。
>
> 本文件是 SKILL.md 阶段 B 的操作细则，不独立成立。

## 核心原则

**世界缺什么，人物就在哪受压。** 世界的缺憾不是背景板——主角的缺憾必须与世界缺憾关联（质量门 11）。世界先于人物：C 阶段的人物从本阶段的受力点里长出来。

## 一、硬规则 6

| # | 规则 | 操作问题 | 判定要点 |
|---|------|---------|---------|
| 1 | **核心异常** | 这个世界最不正常的一件事是什么？（一句话） | 一句话能说清；说不清 = 还没找到异常 |
| 2 | **机制追问** | 它靠什么运转？奖励什么、惩罚什么、默认什么？ | 规则要压到人身上——能答"谁因此能做什么、不能做什么" |
| 3 | **美学辨识度** | 颜色、气味、材质、光线、时代感各是什么？ | 观众一眼可认；照抄现实不够，要有自己的符号 |
| 4 | **世界缺憾** | 世界缺什么？ | 与主角缺憾关联（质量门 11）；无缺憾 = 无压力来源 |
| 5 | **规则代价与执行人 4 问** | 规则由谁定？谁执行？谁承担代价？谁可以豁免？ | 四问缺一问，规则就悬空；"豁免者"往往是反派位置 |
| 6 | **当前局势 + 真相与悬念** | 为什么故事现在发生？世界隐藏了什么？ | "现在"必须有理由——不是任何一天都能启动故事 |

## 二、历史压力 5

世界的厚度来自它承受过的历史，这五组决定"这里的人怎样活着"：

| # | 压力 | 操作问题 |
|---|------|---------|
| 1 | **势力** | 主要势力各自的目的/资源/依靠/彼此冲突是什么？ |
| 2 | **货币与供养** | 最稀缺的东西是什么？谁分配它？谁被延后？ |
| 3 | **阶级身份名分资格** | 谁有资格说话、谁只能沉默？身份如何定义人（被看成什么）？ |
| 4 | **信仰与禁忌** | 什么被相信？什么被禁止？违反者承受什么？ |
| 5 | **日常一天** | 一个普通人怎么过一天？ | 

判断：历史压力不是设定填空——每一条都要能回答"它怎样影响一个具体人物的选择"（人物篇：设定没有压到具体人身上，便只是背景）。

## 三、世界推导七步（缺憾 → 人）

从世界缺憾推出人物与冲突的路径：

```
① 缺憾      → 这个世界缺什么？
② 谁被伤害  → 缺憾最直接压在谁身上？
③ 谁维护    → 谁从现状获益并维持它？
④ 谁知道历史→ 谁知道这个缺憾的来历（它的根）？
⑤ 谁靠漏洞活→ 谁在规则缝隙里讨生活？
⑥ 谁承受日常→ 谁每天在替缺憾付账？
⑦ 主角如何解决 → 主角的路径对准缺憾打（还是成为缺憾的一部分？）
```

- ①-⑥ 的答案就是 C 阶段八受力位置的候选（承受/控制/维护/知情者直接对应 ②③④）
- ⑦ 决定主角的"为"（见 02-character.md）——解决不了也要说清"为什么他不得不试"

## 四、美学辨识度参数化（可填表单）

```

```

## 可判定检查（阶段 B 收尾）

```
[ ] 硬规则 6 全答（异常一句话/机制三问/美学五感/缺憾/代价四问/当前局势）
[ ] 历史压力 5 全答，且每一条都能指向一个具体人物的选择
[ ] 推导七步 ①-⑦ 连续（每一步的"谁"都有名有姓）
[ ] 世界缺憾-主角缺憾关联成立（质量门 11 预检）
[ ] 规则有豁免者（豁免者是谁，已被标记）
```
