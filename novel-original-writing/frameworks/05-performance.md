# 05 — 表演层注入（F 阶段操作细则）

> **理论来源**：本阶段方法论全部出自 07 表演层，**只引用路径，不复制内容**：
> - 六件套方法论：`video-prompt-adapter/frameworks/performance-direction.md`
> - 否定约束库：`video-prompt-adapter/frameworks/negative-constraints.md`
>
> 原创流的特殊点：07 是给单镜头提示词写表演，本协议在剧本阶段就给人物"预装"表演指令——F 阶段产出在剧本里，随剧本进入 07 时可整段搬运。本文件只写组装规则与接口，方法论细节一律指向 07 文件。
>
> 本文件是 SKILL.md 阶段 F 的操作细则，不独立成立。

## 一、四件套（每场关键人物必配）

| # | 件 | 内容 | 引用位置（07） |
|---|----|------|--------------|
| 1 | 角色内在 | 性格气质一句话（"形容词+气质名词"型）+ 表演基调（情绪表达尺度与方式）+ 一致性锚点（脸型/五官/年龄感/发型/气质逐项） | performance-direction.md §1 |
| 2 | 表演心理学 | 内心轨迹三段式（日常态→触发点→内心变化）+ 情绪实质（是什么、不是什么）+ 时间窗口（精确到几秒）+ 潜台词层（每个物理指令补"为什么这么演"） | performance-direction.md §2 |
| 3 | 微表演指令 | 从七类词汇库选 3-6 个可见细节按发生顺序排列（眼神/面部/呼吸/手部/身体/节拍/声音） | performance-direction.md §3 |
| 4 | 否定约束 | 按题材从否定约束库选配，四维全覆盖（声音/字幕/行为/崩坏高发处各 ≥1 项） | negative-constraints.md |

## 二、表演核心行（每场一条）

```
公式：表演核心：[基调词]。重点呈现[3-6 个微表演动作清单]。[禁过度项]
```

- 基调词与角色内在的表演基调保持一致
- 动作清单按"发生顺序"排列（从词汇库选）
- 禁过度项写时序性否定（如"禁止眼泪提前滴落"）

## 三、组装模板（剧本内回填段落）

F 阶段产物直接作为剧本每场的"表演层附件"（不混入动作描述）：

```
【角色内在】[性格气质]。情绪表达[表演基调]。保持[一致性锚点]一致，不换脸不漂移。
【表演】人物先[日常态]，在[触发点]之后，内心[变化方向]。[时间窗口]内，重点表现[微表演清单]。
　——[潜台词：为什么这么演]
【否定】[按题材选配 negative-constraints.md 对应清单]
```

> 源头即外化的延续：C 阶段为-6（内在怎样外化）填的是"动作、姿态、道具、沉默"等载体；F 阶段把这些载体升级为 07 级微表演指令（眼神停顿/动作中段/呼吸变浅等）。两者必须一致——F 不得发明 C 没有的载体，C 的载体不得在 F 阶段丢失。

## 四、风格体系（可选，用于视觉策略统一）

世界观美学（01-world.md 硬规则 3）如需落到画面语言，引用 performance-direction.md §7 的风格体系参数块（基调色/高光色/阴影色/饱和度/反差/质感）——世界观美学是源，调色参数是它的画面化，不是另起一套。

## 可判定检查（阶段 F 收尾）

```
[ ] 每场关键人物四件套齐全（角色内在/表演心理学/微表演/否定约束）
[ ] 表演核心行存在，动作清单按发生顺序排列
[ ] 微表演指令与 C 阶段为-6 载体一致（无发明、无丢失）
[ ] 潜台词层存在（"（情感：…）"格式）
[ ] 否定约束四维全覆盖 + 题材匹配（非通用层了事）
[ ] 一致性锚点逐项列出（换脸/漂移防线）
[ ] 风格体系（如选用）与 01-world.md 美学辨识度一致
```
