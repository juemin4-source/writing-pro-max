# 07 — 质量门 20 条（判定方标注 + 证据 + 检查操作）

> **理论来源**：判定标准全部出自设计文档 original-screenwriting-design-20260801（APPROVED）「质量门（20 条可判定规则）」；判定操作的方法论依据见各对应框架文件。判定方标注约定：**[导演]** = 必须导演判定，机械不得放行；**[机械+导演]** = 机械可查部分自动过，判断部分导演定；**[机械]** = 字段/格式自动检查。
>
> 本文件是 SKILL.md「质量门总表」的操作细则，不独立成立。运行规则：每个阶段收尾在样片摘要中逐条呈现本阶段涉及的门（Gate 证据必须引用具体证据文件）。

## 人物门（1-11）

### 1. 五组问题清单（私9/处9/执7/为7/已6 = 38 问）[导演]

- **证据**：`checkpoints/02-characters.md` 每人一份表单
- **检查**：逐人逐问核对——空答（"不知道/还没想好"）即 FAIL；重要角色 38 问全答，配角至少私+执
- **判定**：答案质量（是否有载体、是否与人物一致）由导演定；空答判定可机械查（字段非空）

### 2. 执四形态 + 阶段变化记录一致 [导演]

- **证据**：`checkpoints/02-characters.md` 执-5
- **检查**：每角色标注当前形态（正/偏/旧/邪）+ 形态变化轨迹（如"正执失度成偏执"）；剧本中执的变化与记录一致——剧本里执变了但表单没记 = FAIL
- **判定**：形态定性由导演定；"剧本变化 vs 记录一致"机械可查

### 3. 执代价落点 [导演]

- **证据**：`checkpoints/02-characters.md` 执-4/执-6、场景卡"关系变化"字段
- **检查**：
  - 落自己 → 悲壮（可接受）
  - 落别人 → 危险（须显形）
  - 落无辜者 → 伤害必须显形：谁受伤、怎么受伤、他看见没有
- **红牌**：出现"为了大局他们可以死"式表述且无辜者伤害未显形 → 回 C 补载体，导演终裁
- **判定**：全部由导演定（道德审查）

### 4. 能力扑街十问（可勾选诊断）[导演]

- **证据**：`checkpoints/02-characters.md` 扑街十问勾选表
- **检查**：十问逐条勾选，任一"否"须有解释或已修复；"能力替人物逃课/无涟漪/不与执反应"= 必须修
- **判定**：勾选结果导演审（勾选动作本身机械可录）

### 5. 万用能力矩阵映射（能力→欲望×正反合可答）[导演]

- **证据**：`checkpoints/02-characters.md` 能力段
- **检查**：每个能力能答三句——服务哪种欲望（生/逸/乐/和/权/变/名/道）？满足/威胁/转化？人物缺口（私）为何让能力有重量？答不出 = FAIL
- **判定**：映射合理性导演定；三句字段齐全机械可查

### 6. 一人多位：重要角色承担位置 ≥ 2 [机械+导演]

- **证据**：`checkpoints/02-characters.md` 八受力位置表
- **机械**：数每个重要角色在八位置（承受/控制/排除/代价/维护/知情/象征/显影）中的承担数——< 2 标记"工具人风险"
- **导演**：承担数 ≥ 2 的角色是否真的多位（位置不是挂名）；只占一位的重要角色是否可降为龙套

### 7. 行动涟漪：关键行动后"谁的位置改变了"有答案 [导演]

- **证据**：`checkpoints/02-characters.md` 为-7（关键行动逐一填写）
- **检查**：每个关键行动（剧本的 TURN 点）后有涟漪答案——谁靠近/离开/受伤/看清他/替他付代价/哪个日常回不去了；无答案 = FAIL
- **判定**：涟漪是否真实（不是"关系更好了"式空话）导演定

### 8. 已的不可逆："哪里回不去了"无答案 = 命运未发生 [导演]

- **证据**：`checkpoints/02-characters.md` 已-6 + `checkpoints/08-ending.md` 不可逆复核
- **检查**：主角至少有一条不可逆（关系/身份/能力/信念/日常层面）；无 = FAIL
- **判定**：不可逆的真实性导演定

### 9. 新生落实到为：无新行动方式 = 心理旁白 [导演]

- **证据**：`checkpoints/02-characters.md` 已-1 + 为-3（剧本后段行为）
- **检查**：人物"新生"（长出什么）必须对应新的行动方式（为-3 第一反应从 X 变成 Y）；只有内心描写没有新行动 = 心理旁白，FAIL
- **判定**：行动方式的新旧导演定

### 10. 开头名/结尾名对照（证明/推翻/重铸/反讽）[导演]

- **证据**：`checkpoints/00-seed.md` logline + `checkpoints/08-ending.md` + 已-5
- **检查**：结尾与起点的关系四选一——证明（起点被守住）/ 推翻（起点被否定）/ 重铸（起点以新形态存在）/ 反讽（起点以讽刺性收场）；四选一写不出 = 弧度未闭合，FAIL
- **判定**：导演定

### 11. 世界缺憾-主角缺憾关联 [导演]

- **证据**：`checkpoints/01-world.md` 硬规则 4 + `checkpoints/02-characters.md` 私/处
- **检查**：世界缺什么、主角缺什么、两者如何关联——主角的解决路径对着世界缺憾打；无关联 = 世界是背景板，FAIL
- **判定**：导演定

## 命运门（12-20）

### 12. 二十四节气验收句（24 条，逐场/逐幕可判）[导演]

- **证据**：`checkpoints/03-structure.md` 节气标记（每条线每幕的节气标注）
- **检查**：抽查关键幕——该幕对应验收句（03-structure.md §二）是否成立；如"夏至 处有没有照出裂口""秋分 处旧暧昧是否结束"
- **判定**：导演按验收句逐条审（验收句是理论核心，判定即对照原文语感）

### 13. 失候清单红线扫描（6+2+5+4+2 条）[机械+导演]

- **证据**：`checkpoints/03-structure.md` 失候勾选表
- **机械**：19 条逐条勾选，0 命中 = PASS；命中条数随样片摘要上报
- **导演**：命中的失候是否构成 FAIL（如"该杀的时候舍不得断"= 必须修）或可接受风险（WARN）

### 14. 支线接入"将"位 [导演]

- **证据**：`checkpoints/03-structure.md` 时位细纲（支线接入点标注）
- **检查**：每条支线标注接入时位（将动/将育/将杀/将藏）；支线占正节点或高潮才并线 = FAIL
- **判定**：接入时位是否准确导演定

### 15. 大中小周期对齐 [导演]

- **证据**：`checkpoints/03-structure.md` 大中小周期对照表
- **检查**：4 组对照——主线入秋支线不春花 / 主角夏至反派不才立春 / 世界线霜降某段关系不到雨水 / 卷尾归藏全书不才小满；错位 = 说明原因（允许的错位须是刻意设计）
- **判定**：导演定

### 16. 秋分不可逆 [导演]

- **证据**：`checkpoints/03-structure.md` 秋分处（列出被切断的退路）+ `checkpoints/06-screenplay.md` 秋分段
- **检查**：秋分后不再保持暧昧状态——退路被断掉至少一条；剧本秋分后的段落有新的不可逆状态；暧昧延续 = FAIL
- **判定**：导演定（G 阶段复核）

### 17. 信息分配一致性（七选一 + 一致执行）[机械+导演]

- **证据**：`checkpoints/03-structure.md` 叙事大纲（信息分配七选）+ 章纲"释放或隐藏什么信息"字段
- **机械**：七种中选了一且各章信息字段与选择一致（顺叙则无倒叙插叙结构；不给完整答案则结尾无全盘解释）
- **导演**：选择本身与情绪承诺匹配（承诺悬疑却全程顺叙平铺 = 不匹配）

### 18. 章纲七要素完整性 [机械]

- **证据**：`checkpoints/03-structure.md` 章纲（视点/事件/动机/阻力/变化/信息/钩子）
- **机械**：每章七字段齐全——缺一字段即 FAIL；无变化字段 = 该章是否存在的疑问自动上报

### 19. 盆景七问（主景/辅景/对景/借景/路径/疏密/藏露）[导演]

- **证据**：`checkpoints/03-structure.md` 盆景七问结论
- **检查**：七问各有一句结论（03-structure.md §七判定要点）；主景无力 / 辅景喧宾夺主 / 对景孤立 / 借景挖坑 / 路径迷路 / 疏密太满 / 藏露失衡——任一命中即需返修
- **判定**：全部导演定

### 20. 藏露分寸（水下的必须影响水面，不影响 = 删）[导演]

- **证据**：`checkpoints/03-structure.md` 藏露清单
- **检查**：每个水下设定（前史/规则/关系旧账/主题暗线）标注它影响水面的方式（影响哪个动作/哪句对白/哪个物件）；标注不出 = 作者私设，删
- **判定**：导演定

## 整体性 gate（第 21 项之外的警惕机制）

**不是第 21 条可判定检查**——它是不可完全判定的审美机制（存在性检查永远查不出分量问题）。细则见 SKILL.md「整体性 gate」节。本文件补充：

- **与 20 条的关系**：20 条全过是必要条件，不是充分条件——报告/样片摘要中整体性 gate 的结论单独列出（"分项全过 / 整体成立 / 落差项"）
- **落差的常见形态**（E2E 实测案例《第十七道痕》）：执有来路但无重量 / 节气到位但事件轻 / 失候 0 但节奏平 / 值得写三问答了但"多出的一刀"不锋利——落差即哪条检查"只查了存在"
- **AI 主动喊停的记录**：喊停必须写 director-log（decision=accept/cut/terminate + 整体性依据），不得静默
