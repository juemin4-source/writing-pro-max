# 00 — 种子期（A 阶段操作细则）

> **理论来源**：低入口高经验/通俗与庸俗 ← 《故事天演论》导论-第一章；欲望八象完整四层 ← 《故事天演论》第二章（与《人物篇》八欲望同构）；类型与场域 ← 《故事天演论》第三章；欲望分层 ← 《故事天演论》第四章；故事前提/故事生长法/值得写 ← 《故事天演论》第五/六/七章；尺度问题 ← 《人物篇》第一章；私生人物 ← 《人物篇》第三章；叙事入口与冬至暗动 ← 《命运篇》第五章/第三章；概念组合骨架 ← @山音 screenwriting-master（MIT，只借骨架；其 S/C/T 三件套被本章内外分端吸收后仅作参考）。五秒可理解检验承接神之公式的 R（阅读阻力）预判。
>
> 本文件是 SKILL.md 阶段 A 的操作细则，不独立成立。核心目标：**让一个想法变成别人愿意继续追问的局面**，并且**入口很低、经验很高**——门要开得清楚，但门后必须有世界。

## 交互模式（默认：引导式追问，不一口气编前提）

**种子期是和用户一起根据理论追问出前提**——材料必须由用户给出，AI 只做三件事：

```
① 出示理论工具与问题（本文件各节就是"带着理论的问题"）
② 整理用户已提供的材料（前提句草案 = 用户答案的组合稿，不是 AI 的创作）
③ 用理论校验与反问（"这个外部局面里，欲望真的被压住了吗？""六变一常选的是哪一常？"）
```

- 用户没答的题，AI 不发明答案——宁可停在这一轮继续追问
- 每轮用户确认后才写入 checkpoint；checkpoint 每项标注「用户提供 / AI 整理 / 用户确认」
- **代写例外**：用户显式要求"你帮我编/直接生成"才进入代写模式——代写产物逐条标注材料来源（哪些来自用户、哪些是 AI 补的），并回传用户逐项确认
- 全轮次节奏表见 SKILL.md「A 种子期·追问节奏（13 轮）」，本文件各节即各轮的问题工具

## 一、作者愿望清单：先拿到原矿

**交互（轮 1）**：问用户"最近反复想写什么？"——AI 不替用户列愿望，只负责把用户列出的原矿分类。若用户只有一句话（"我想写个关于 X 的故事"），就此开始，不必凑满 10 条。

创作的起点不是理论，是一堆原矿。先收集作者反复发热的材料——不要求像故事：

```
作者愿望（先列 10 条左右，任选来源）：
- 人生经验类：想重新开始 / 想离开困住自己的地方 / 弥补一次错过 / 努力多年仍未抵达想要的生活
- 关系类：母女亏欠 / 父子沉默 / 无法说出口的爱 / 既渴望靠近又本能逃走
- 命运类：宿命 / 翻身 / 怕什么来什么 / 一步之遥 / 被错误命名后夺回自己
- 类型快感类：悬疑 / 复仇 / 重生 / 末日 / 权谋 / 治愈 / 闯入陌生世界
- 审美物象类：雪夜 / 旧宅 / 医院走廊 / 废墟城市 / 地铁末班车 / 永远亮灯的便利店
```

再分三类：**人物心里想要的东西**（欲望）/ **外部世界可以发生变化的东西**（材料）/ **作品以后可能通向的深处问题**（主题）。例："我想写一个人重新开始"= 欲望；"我想写一栋活着的建筑"= 外部材料；"我想写稳定为什么越来越贵"= 深处问题。

## 二、内：欲望八象（人物为什么会动）

**交互（轮 2）**：问用户"这个材料里，人物可能有什么欲望？"——AI 用八象表帮用户辨认（"你说的'想活'对应生象；'想被看见'接近名象"），由用户确认，不替用户定。

> 八个字观察欲望：**生、逸、乐、和、权、变、名、道。** 每个象都是一枚硬币：阴面是恐惧与匮乏，阳面是渴望与生长，失度是陷阱，深处问题是高经验的方向。

| 象 | 入口感 | 阴面（怕什么） | 阳面（求什么） | 失度（陷阱） | 深处问题（门后的世界） |
|----|--------|---------------|---------------|-------------|----------------------|
| 生 | 他能不能活 | 死/匮乏 | 活命、生机、生路 | 为活把生毁掉（把人变燃料） | 活下来以后，人还剩下什么 |
| 逸 | 他能不能歇 | 累/漂泊/过劳 | 安顿、舒展、恢复 | 安顿变停滞，舒适变牢笼 | 获得安顿而不把安顿变成新的牢笼 |
| 乐 | 好不好玩 | 无聊/麻木/压抑 | 喜乐、游戏、生命感 | 被快乐麻醉（消费循环） | 在沉重世界里保存活力而不被快乐麻醉 |
| 和 | 他们能不能在一起 | 孤独/被弃 | 连接、互认、共同生活 | 强合：以爱/家/集体之名把人吞掉 | 与人相连而不互相吞掉 |
| 权 | 他能不能说了算 | 无力/被动 | 主动、判断、位置 | 支配操控、权力成瘾 | 获得主动以后，如何不变成新的压迫者 |
| 变 | 他能不能改命 | 困在原路/死局 | 更新、破局、转机 | 投机、否认过去、逃避代价 | 改变命运时，是否也改变了自己面对命运的方式 |
| 名 | 他能不能被正名 | 污名/无名/被错误定义 | 名实相符、承认、身份归位 | 被评价体系绑架（一生向旧体系证明） | 夺回名字以后，能不能不靠别人的承认活着 |
| 道 | 真相到底是什么 | 迷乱/无路/失序 | 明白、道路、秩序 | 迷道邪道、拿道理压死人 | 明白世界以后该往哪里去（如何不被世界吞掉） |

**八象不是单选题，是一次扫描**：

```
这个前提调动了哪些欲望？___
哪一种最适合成为读者入口？___（入口欲望清楚，读者就知道自己为什么要进入）
哪些留到后面加深？___
```

欲望稳定下来，就会生成类型——悬疑是道被稳定组织、言情是和、求生是生、重生是变、权谋是权、正名是名。读者看见类型，是在看见"这里将处理哪种欲望、触碰哪种缺憾、带我进入哪种经验"。

## 三、外：六变一常（世界怎样让欲望不能安稳）

**交互（轮 3）**：把七入口逐个出示给用户，问"你的材料里，世界可以发生哪种变化？"——每个入口给出触发问；用户选了之后 AI 指出这种选择的类型气质（变→卡夫卡式、异→都市怪谈、耗→伦理惊悚…），由用户确认。

> 外部局面的七个入口——**变、扰、异、耗、散、塞、常。**

| 入口 | 定义 | 触发问 |
|------|------|--------|
| 变 | 稳定之物改变了性质 | 如果这世界最稳定的一件事突然改变，会发生什么？（身体/时间/梦/规则） |
| 扰 | 原有秩序被打断 | 什么事情一出现，原来的生活就再也无法照常维持？（信/归来/债务/鬼魂/旧案） |
| 异 | 不属于这里的东西闯进来 | 如果一个完全不属于这里的系统突然接入日常，会发生什么？（魔法入日常/地府入微信群） |
| 耗 | 维持好处需要付代价 | 如果安全、幸福、繁荣必须靠持续消耗某些人或东西维持，会发生什么？（奥米拉斯/克隆捐献/饥饿游戏） |
| 散 | 完整之物裂开了 | 如果完整的真相、记忆、身份被拆散，会发生什么？谁拿着哪一块？（竹林中/记忆碎片） |
| 塞 | 通往欲望的路被堵住 | 如果人物想要的东西很清楚，但所有正常路径都走不通，会发生什么？（审判/楚门） |
| 常 | 一切照常继续 | 如果一切继续这样下去，人会怎样？（活着/请回答 1988/小森林） |

只看外容易变奇观，只看内容易停心理愿望——**前提出现在内外相交处**。

## 四、内外相交：前提句 + 三个剧情追问

**交互（轮 4-5）**：前提句草案 = **只组合用户在前三轮给出的材料**（愿望/欲望/变化），AI 整理成句交给用户改；用户改定后才进三个剧情追问（问用户"读者会自然问哪三个问题？"，AI 校验追问是否推动故事、答案是否在局中）。AI 不得在草案里加入用户没提过的人物、事件或设定。

```
| 步骤 | 问题 |
|------|------|
| 作者愿望 | 我最近反复想写什么？ |
| 内 | 这个材料里，人物可能有什么欲望（八象）？ |
| 外 | 这个材料里，世界可以发生哪种变化（六变一常）？ |
| 相交 | 这个外部局面怎样压住、扭动或逼近人物欲望？ |
| 追问 | 读者会自然问哪三个剧情问题？ |
| 前提 | 写成一句让人想继续看的局面。 |
```

前提句写法：不要填死模板，像向朋友讲一个点子：

> 一个对生活绝望的人，为了让家人得到保险，雇了一个笨杀手把自己伪装成意外死亡；可第二天他突然中了一个亿，于是必须在杀手不断制造"意外"之前，把自己从自己买下的死亡里救出来。

**三个剧情追问**（至少三个，不急着问"这意味着什么"，先问推动故事的问题）：

```
他会怎么做？  谁会阻止他？  代价会落到谁身上？
他还能不能回到原来的生活？  真相在谁手里？
事情会怎样继续扩大？  失败以后会失去什么？
```

**五秒可理解检验**（神之公式 R 预判）：前提句讲给完全不了解背景的人，五秒内答得出"关于谁、出了什么事"。听不懂 → 砍细节不砍概念。

**高概念只是前提的一种强形态**（"如果恐龙被克隆进主题公园，会怎样"级）：能强烈转述当然好，不能一句话炸开也成立（《活着》没有强设定）。关键是有没有欲望、有没有外部局面、有没有继续追问的空间。

## 五、低入口高经验验收（前提的质量标准）

**交互（轮 6）**：把入口四件事逐件问用户（"你的前提里，这个人缺什么？想要什么？什么挡住了他？"），再逐条过失真检查（"主角赢会有后果吗？"）——检查结果由 AI 按理论判定，**问题回传用户修**，AI 不替改。

> 《故事天演论》导论-第一章：**入口很低，经验很高。** 通俗是高保真压缩，庸俗是失真压缩。

**低入口**：前提句应让读者很快看清四件事——
1. 这个人缺什么
2. 他想要什么
3. 什么挡住了他
4. 这件事为什么值得继续看

**失真检查**（压缩是否损坏了经验——**欲望不能绕开世界**）：
```
[ ] 主角赢，有没有后果？（胜利取消后果 = 失真）
[ ] 人物成长，有没有旧我的撕裂？（一键成长 = 失真）
[ ] 爱情圆满，有没有真正处理伤害？（一句道歉抹平 = 失真）
[ ] 反派受罚，有没有降智？（反派忽然失去智商 = 失真）
[ ] 世界是否变成欲望的服务员？（为读者爽而让路 = 失真）
```
成熟的作品让欲望穿过阻力、代价、误判和后果——承认需要证据，爱有边界，复仇有后果，自由意味着无人兜底。**判断入口是否庸俗，不要只看它好不好懂，要看它压缩后保留了多少真实阻力。**

**四象限定位**：

| 类型 | 入口 | 经验 | 结果 |
|------|------|------|------|
| 浅层商业 | 低 | 低 | 容易消费，难以长久（警告） |
| 自我封闭的高级 | 高 | 高 | 有价值但门太窄 |
| 伪高级 | 高 | 低 | 难读又空（最糟糕） |
| **大众经典（目标）** | **低** | **高** | 容易进入，长久留存 |

## 六、私生人物检验（前提生成力）

**交互（轮 7）**：问用户"这个前提能长出几种不同'私'的人？"——AI 用**用户材料**示范 1 个（把用户提到的欲望/处境落成一个"私"），引导用户再想 1-2 个；用户想不出来时 AI 才给候选，且标注"AI 补充"。生成力不足时回轮 3 修外部局面。

> 《人物篇》第三章：**同一个前提，只要"私"不同，就会长出完全不同的人。**

以"被拉进地府鬼差工作群续命"为例：怕失业的人（把"稳定"纳入我）→ 现实荒诞；想翻身的人（把"出人头地"纳入我）→ 职场寓言；失去亲人的人（把"再见一面"纳入我）→ 悼亡与告别。

**检验**：给当前前提捏出 ≥2 种不同"私"的人物（各问：他把什么纳入"我"？表面上想要什么？真正缺什么？什么让他马上 get / 完全 get 不到？）：
- 能捏出 ≥2 种且气质不同 → 前提有生成力（每种"私"长出不同故事方向）
- 只能捏出一种 → 前提窄，回第四节修外部局面（通常是外不够，六变一常没选准）

这个检验同时是 C 阶段人物生成的预检——捏出的"私"直接进 02-character.md 的私九问。

## 七、类型与场域（前提的容器，接 B 阶段）

**交互（轮 8）**：问用户"这个世界在哪发生？那里有什么规则挡人？"——用户给出场域后，AI 用"医院/宫廷/末日"式示例提示规则维度（床位/名分/水源…），由用户确认至少 3 条规则且每条都阻挡欲望。

> 《故事天演论》第三章：**类型是欲望进入场域、受到规则阻拦后形成的读者可识别的承诺。**

**场域不是背景，而是欲望受阻的地方**：医院的规则不只是白大褂——还有床位、费用、签字权、家属意见、药物渠道；宫廷的规则不只是古风——还有名分、座次、血统、礼法、沉默与杀机。场域真正回答的是：**这个世界怎样让人物想要的东西变得困难。**

```
前提的场域：___
场域规则（至少 3 条，每条都要能阻挡欲望）：___ / ___ / ___
同一场域能长出的其他类型（验证场域厚度）：若核心欲望是生→___；是道→___；是名→___；是逸→___
类型承诺（一句话）：<欲望> 进入 <场域>，被 <规则> 阻拦，读者将等待 <什么>
```

**类型承诺持续生长三件事**（接 D 结构期验证）：① 欲望能持续受阻（不能太容易得到）② 阻力能不断变形（今天怪物、明天规则、后天自己）③ 代价能不断加深（体力→关系→身份→信念→对世界的理解）。

**类型是第一只盆**（对接《命运篇》盆景隐喻）：盆不替树生长，但决定最初的尺度、气质和观看方式——盆太浅根扎不住，盆太大树会散。**接 §十一尺度路由与 B 阶段**：场域规则清单直接喂给 01-world 的机制追问（奖励/惩罚/默认）。

## 八、欲望分层（验证"门后有没有世界"，接值得写）

**交互（轮 9 前半）**：问用户"这个入口欲望，门后的世界会是什么？"——用 8 经典路径对照，AI 指出"你选的入口欲望，成熟写法通常通向 <深处问题>"，由用户确认或修正。

> 《故事天演论》第四章：每个故事都有一个容易进入的欲望，让读者愿意进来；但故事只满足这个欲望很快就会变浅——**成熟作品会让入口欲望继续往下走。** 八个经典路径：

| 入口欲望 | 经典案例 | 低入口 → 高经验 |
|---------|---------|----------------|
| 生 | 《活着》 | 能不能活下去 → 一再失去之后，为什么仍然活着 |
| 逸 | 《小森林》 | 疲惫的人慢下来 → 人如何从失速生活里重新获得节律（安顿不是逃走） |
| 乐 | 《西游记》 | 好玩/奇观/斗法 → 以乐为入口，以道为归处（求道不写硬） |
| 和 | 《请回答 1988》 | 共同生活的温度 → 相连之美正因为会经过时间、终将离开 |
| 权 | 《死亡笔记》 | 我能审判别人吗 → 获得权力后如何把自己神圣化（最危险的是如何解释自己） |
| 变 | 《土拨鼠之日》 | 困在同一天 → 真正要改变的不是那一天，而是那个人 |
| 名 | 《哪吒》 | 我不该被这样定义 → 人能不能不被错误的名字写死（夺回名字≠夺回自由） |
| 道 | 《诡秘之主》 | 这个世界是什么 → 看明世界以后，如何不被非人秩序吞掉（知道越多越危险） |

**用法**：给前提选定入口欲望后，用对应"深处问题"验证：前提能通向它吗？答不出 = 只停在入口欲望 = 会变浅（如只写"重生爽"而不问"改命后带着旧我的恐惧怎么办"）。**欲望分层表同时是值得写 gate 的纵深判据。**

## 九、生长法三向 + 叙事组织法（接 D 结构期）

**交互（轮 9 后半）**：问用户"这个追问，你希望往哪个方向长？"——三向各给出该前提的可能路径（用用户材料举例），用户选主路后 AI 确认叙事组织法。

> 《故事天演论》第六章：**展开是改变追问**——一个前提只有第一问，很快就会耗尽。

前提提出第一问后，追问必须持续变形，三向选一条主路：

| 方向 | 做法 | 适合 | 叙事组织法 |
|------|------|------|-----------|
| 向外扩大 | 从一个人牵连到组织/制度/空间/规则 | 世界观/群像/制度叙事 | 任务/地图/阶层递进/区域探索 |
| 向内逼近 | 外部事件压到人物心里，逼近他逃避的东西 | 人物变化/关系/心理悬疑 | 关系递进/旧事浮出/一次次选择 |
| 向后反噬 | 每次解决产生新后果，局面更糟 | 黑色悬疑/因果链 | 倒计时/循环/债务/补账/连锁后果 |

```
这个前提的三向潜力：外扩会到___ / 内逼会到___ / 反噬会到___
主路选：___（三向不必全写，先知道哪条是主路——作品气质由此决定）
谁承受主要追问，谁就更接近主角（地府群里主角可以是社畜/鬼差/名单上的人，取决于主要追问）
```

生长法定义：**作者选择一种方式，让前提提出的第一追问继续变形，并用合适的叙事组织法持续推进。** 主路结论直接喂给 D 结构期的时位细纲（信息分配方式随主路定：靠时间逼迫用时间结构、靠真相拼合用碎片结构、靠规则扩大用任务/地图结构、靠代价累积用名单/账本/轮次）。

## 十、值得写 gate（立项判定）

**交互（轮 10）**：三问逐问用户（"没有掌声和收益，你还想写下去吗？""你给读者的第一份承诺是什么？""最先给读者的消费快感是什么？"）——AI 不替答；缺憾连时代的追问由 AI 提出（"这个人的缺憾，能连到更大的时代缺憾吗？"），答案由用户给出。

> 《故事天演论》第七章：**一个故事在进入正式写作前，必须经得起追问——它有没有继续发展的资格？** 作者、读者、市场三者缺一不可。

```
三问：
1. 我为什么非写它不可？（没有市场反馈、掌声、立刻收益，我还想写下去吗？——碰到我的愿望/不甘/判断）
2. 读者为什么愿意进来？（我给读者的第一份承诺是什么？承诺了悬疑就要认真处理真相——读者怕你赖账）
3. 它卖的到底是什么？（最先给读者的消费快感是什么？成熟作品让快感穿过代价、阻力和人物变化）
```

附加判定：
- **货架**：这部作品应该被放在哪个货架上？读者会带着什么期待打开它？（想反类型也要先懂类型——不懂承诺就谈不上改写承诺）
- **多出的一刀**：和同类相比多出的那一刀是什么？（情绪更狠/结构更妙/人物更疼/缺憾更深/时代连接更准——"这个故事我好像见过，但这一刀我没见过"）
- **规模匹配**：这个故事的规模和我的能力/时间/材料/媒介匹配吗？（能开大局很好，但野心需要结构：哪些是树干哪些是枝叶）
- **四象限定位**（§五）：目标是大众经典（低入口+高经验），不是浅层商业也不是伪高级
- **欲望分层**（§八）：入口欲望能通向对应"深处问题"（纵深验证）

**个人缺憾连时代缺憾**（接 B 阶段世界缺憾）：人物的缺憾能不能连到更大的时代缺憾？——一个人不敢爱不只是冷漠，他可能活在所有关系被成本、风险、匹配重塑的时代。**低入口通向高经验**：从一个具体的人进入，让读者看见"他的痛也是我们共同处在的某种结构制造出来的痛"。但**不要把时代写成口号**：大问题落到小东西上（一张病床/一封通知/一个被删除的名字），让判断在读者心里慢慢发芽。

## 十一、尺度路由（接格式路由）

> 《人物篇》第一章：写世界观第一步是判断尺度——**尺度和深度无关，小不是弱，大也不是强。**

| 尺度 | 定义 | 典型 |
|------|------|------|
| 小 | 人物命运由一条规则逼出 | 旧房子/后院/一条异常规则（听见植物说话→后院埋尸） |
| 中 | 命运由家庭/阶层/职业/资源/身份共同作用 | 现实/都市悬疑/医院/学校/家族 |
| 大 | 命运由时代共同制造，人物与时代冲突 | 战争/权谋/科幻废土/架空史诗 |
| 文明 | 文明如何看见自己、延续、毁灭、重新命名自身 | 史诗/文明兴衰 |

**路由规则**：写文明危机就不要只拿私人恩怨糊弄；写家庭饭桌的沉默不必扩成三代国家史；写科幻要让技术改变身体/身份/亲密/法律/死亡。小故事一刀准也能刺得很深——**大世界没有调用，只是空架子**。尺度决定格式路由（短剧/单集/长片/系列）与 B 阶段世界生成的范围。

## 十二、叙事入口（《命运篇》三依据 · 六切口）

保留《命运篇》第五章规则：**三依据**——情绪承诺（悬疑→不对劲/复仇→债/爱情→位置变化/成长→旧答案不够用/时代悲剧→大时代落小人物）、读者距离（近/中/远）、主题弧度（从哪种理解走向哪种理解，**入口不能和主题终点一样**）；**六切口**——从冬入（旧局切口）/ 从春入（破口切口）/ 从夏入（成局切口）/ 从秋入（清算切口）/ 从归藏入（余波切口）/ 从误解入（假答案切口）。

补充《故事天演论》入口欲望（§二）：**入口欲望清楚，读者就知道自己为什么要进入**——情绪承诺与八象入口感对应（承诺悬疑 → 道象；承诺爱情 → 和象；承诺改命 → 变象）。

## 十三、冬至暗动检验（前提的"雪下有动"）

> 《命运篇》第三章冬至验收句：**这条命运线在显出来以前，是否已经有了暗动？** 没有暗动，人物就是空的；暗动说得太明，冬又散了。

前提句完成后，回查：这个前提里，命运线露头之前，旧局里已经有什么在暗处动了？（人物怎样把不正常过成日常/某个缺口已在暗处动）。**最好的前提是读者还不知道答案，却已经感觉雪下不平**——logline 若只是"事件清单"，回第四节补暗动。此项预检 D 结构期的冬至位（质量门 12 第一条）。
