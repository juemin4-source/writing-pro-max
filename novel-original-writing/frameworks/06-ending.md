# 06 — 余震期（G 阶段操作细则）

> **理论来源**：归藏检验与结尾冬的节气（大雪/冬至）出自用户自著《命运篇》第三章「9.冬：这个故事承诺怎样归入新的旧局」与第三章「2.归藏、生动、长育、止杀」；余震理论出自用户自著《文学天演论：人物、命运与余震》（"结尾没有余震，便只是停止"；"真正的余震不是留坑，余震是意义没有耗尽"；"余震来自前面所有不可逆变化"）。大雪 gate 的"余震 vs 续集钩子"判定是本协议对其的理论操作化。
>
> 本文件是 SKILL.md 阶段 G 的操作细则，不独立成立。

## 核心原则

**结尾不是把事件交代完，而是让读者看见：这一轮发生过的事，怎样改变了人物、关系和世界的常态。** 结尾的冬不是回到原来的冬，是新冬——这一轮的结果沉入新的土里，成为下一轮的土壤。

## 一、大雪 gate（质量门 12 末条复核）

> 二十四节气的最后一条：**大雪最重要的，不是制造续集钩子，而是保留余震。**

验收句：*余震留在雪下了吗？*

| 检查 | 判定 |
|------|------|
| 喧闹真正落幕：不是所有情绪都要继续喊、不是所有问题都要继续解释、不是所有伏笔都要当场拆开 | 未落幕 = FAIL（结尾像散会） |
| 有些问题不必再追——它会在读者心里继续响 | 全部追尽 = FAIL（说得太尽） |
| 雪下留痕：暗处仍有新问题（一段没彻底说开的关系/一个被雪盖住的痕迹/一个旧制度留下的小缺口），但**不必把故事重新打开** | 重新打开 = FAIL（变成新一轮开场） |
| 区分余震与钩子：余震 = "命运没有被彻底用完"；钩子 = 强行开新坑 | 写成钩子 = FAIL（质量门 12 红牌） |

## 二、冬至 gate（种子够小，不开新坑）

> 结尾的冬至可以显写，也可以不写——有些故事大雪后就该结束。若写，是雪下的一点水声。

验收句：*雪下的水声够小吗？*

- 冬至的动，要小——小到像水泉在冰下动：一个旧物换了主人、一段关系留下新的沉默、一个孩子问出一句话、人物在新的日常里第一次做出不同于过去的反应
- 动得太大 = 结尾变成新一轮开场，归藏被破坏——**不写新冲突，只让读者感到"故事结束了，但命运没有死"**

## 三、归藏检验（三查）

| # | 检验 | 操作问题 | 判定要点 |
|---|------|---------|---------|
| 1 | 新常态入日常 | 结果进入现实了吗？ | 不是"后来怎么样"，是"结果已经进入现实"：路怎么走、门怎么开、谁能说话、谁被记住，都和以前不一样了（立冬验收句）；旧物换形——敌人死了但逻辑留在制度里 |
| 2 | 关系结霜 | 人物之间重新定位了吗？ | 谁还能站在一起、谁不能回头、谁欠谁、谁终于看见谁、谁虽然活着却已失去原来的位置——关系要有明确新状态（寒露的延续） |
| 3 | 未耗尽问题 | 故事结束但问题还在吗？ | 大雪之后留一个"不必追但会响"的问题；无 = 解释干净，FAIL（说得太尽） |

## 四、余震三问（天演论）

> 深刻不是大词（死亡/命运/自由），深刻来自余震：故事结束后，读者仍然无法轻易完成判断。

```
[ ] 1. 故事结束后，读者仍然无法轻易完成判断吗？
      （这个人真的错了吗？她真的自由了吗？这个胜利会不会变坏？——无法轻易下判断 = 余震成功）
[ ] 2. 人物承受了观点之后，留下复杂性了吗？
      （人物是传声筒则无余震——"读起来很正确，却没有余震"）
[ ] 3. 结尾留的是余震，还是解释清楚？
      （"结尾要有余震，而不是解释清楚"——解释干净 = 失败）
```

余震三问与 D 阶段的主题弧度（00-seed.md：从哪种理解走向哪种理解）闭合：入口给初始理解，G 阶段确认"读者离开时的理解"没有变成"标准答案"。

## 五、不可逆复核（跨阶段）
