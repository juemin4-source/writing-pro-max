# 04 — 载体翻译期（E 阶段操作细则）

> **理论来源**：章纲七要素出自用户自著《命运篇》第三章「大纲写法·章纲」；场/幕结构与剧本硬规则语义与 02 改编协议（novel-to-screen-adaptation）一致——本文件**只引用 02 模板路径，不复制内容**：场景卡字段与校验清单见 `novel-to-screen-adaptation/templates/scene-card.md`，剧本场景格式/好例坏例/硬规则见 `novel-to-screen-adaptation/templates/screenplay-scene.md`。流程形态（先场景卡→节拍表→剧本正文）借 @山音 screenwriting-master 骨架。
>
> 本文件是 SKILL.md 阶段 E 的操作细则，不独立成立。

## 一、章纲七要素 → 场/幕结构

章纲七要素（视点/事件/动机/阻力/变化/信息/钩子，见 03-structure.md §八）产出后，做场/幕拆分：

1. **视点决定镜头主语**：一章可拆多场，每场保持单一视点；换视点 = 换场
2. **一场只完成一个功能**：功能唯一（与其他场不重复）；功能写不出来 = 这场不该独立成场，合并到相邻场（02 场景卡 Hard Rule）
3. **幕的结构**：短剧/单集按节拍走；长片/系列先定幕（幕 ≈ 大节气组：春幕/夏幕/秋幕/冬幕），幕内再排场

## 二、场景卡（9 字段，引用 02 模板）

每场用 02 模板 `templates/scene-card.md` 填写，字段为：目标 / 阻碍 / 冲突 / 变化 / 信息揭示 / 关系变化 / 屏幕物件 / 内心外化 / 视觉策略，另附结束状态与可删判定。校验清单（02 原文语义）：
- 目标具体可见可拍（不是"想要幸福"）
- 阻碍具体可拍（不是"命运"，是"门锁了；敌人进来了"）
- 冲突外部可见（不是"内心挣扎"，是"两人对峙"）
- 关键信息揭示（观众知道了什么新信息？）
- 关系变化（靠近/远离/反转）
- 结束状态明确（从 X 变成 Y）
- 功能唯一（与其他场不重复）
- 可删=yes 时真的可以删

> 原创流与改编流的差异在此阶段最不明显：改编流是"内心信息外化"的转译记录（loss/fidelity/compensation），原创流不需要——人物的内心在 C 阶段生成时就已经以可拍载体设计（02-character.md 为-6：内在怎样外化）。场景卡的"内心外化"字段在原创流里是从人物卡回填，不是新转译。

## 三、节拍表

场景卡之后、剧本正文之前，每场一节拍表：

```
BEAT 1: <动作/信息>
BEAT 2: <动作/信息>
        TURN: 从"X"到"Y"（人物立场/认知的变化点）
...
EXIT: <这场结束时的画面/状态>
```

- 节拍必须写 TURN 点——无 TURN 的节拍表 = 事件流水账
- 节拍顺序 = 剧本正文的动作顺序；跳过节拍表直接写剧本 = FAIL

## 四、剧本正文与硬规则（引用 02 协议语义）

剧本正文用 02 模板 `templates/screenplay-scene.md` 的格式（内/外 · 地点 · 时间 + 动作 + 对白 + 转场；对白和动作互打断；潜台词优先）。**剧本硬规则与 02 协议语义一致，本协议不重复发明，逐条引用语义并验证**：

```
[ ] 场景标题包含名称 + 内/外 · 地点 · 时间
[ ] 动作描述占比 ≥ 40%
[ ] 每段对白 ≤ 3 句（否则打断或压缩）
[ ] 无不可拍词：她感到/她意识到/她记得/她突然明白 → 死刑（用身体动作、环境反应、物件细节传递）
[ ] 对白必须有潜台词（不直接说意图）
[ ] 每个场景有转场（至少 ---）
[ ] 开场第一个画面有视觉 hook（30 秒内建立世界）
```

## 五、原创流特定检查（超 02 部分）

原创流没有源文本锚点，用概念锚点补位：

```
[ ] 每场可回溯到 logline 零件（S/C/T 至少一个）——回溯不到 = 概念漂移
[ ] 每场的"变化"与人物的执/为/已一致（02-character.md 的五层表单为真源）
[ ] 场景卡的"屏幕物件"与 01-world.md 的美学符号一致（世界辨识度不因场景切换丢失）
```

## 可判定检查（阶段 E 收尾）

```
[ ] 章纲七要素 → 场拆分完成，每场功能唯一
[ ] 场景卡 9 字段全填 + 校验清单全过（质量门 18 复核）
[ ] 节拍表每场有 TURN 点
[ ] 剧本硬规则 7 条逐条验证（动作≥40% 机械可算；对白≤3 句机械可数；不可拍词机械可搜）
[ ] 概念回溯：抽样 3 场可回溯 logline
[ ] 与人物表单一致：无"人物突然会了/突然懂了"无载体变化
```
