# 02 — 人物生成期（C 阶段操作细则）

> **理论来源**：本文件全部方法论出自用户自著《人物篇》：八步操作法（第二章「八、实际操作」）、八受力位置（第二章「故事位置」）、五组问题清单（第三至七章：私/处/执/为/已）、执四形态（第五章「五、执的四种形态」）、万用能力矩阵与扑街十问（番外「能力」）、位置会挪移（第二章「七、位置会挪移」）。两处冲突备忘（与常见写法不同，以本篇为准）：① 执不是创伤机制——恩情/教育/誓言/职业/信仰也能生执；② "未竟"比"完成"更有力——不强制闭合。
>
> 本文件是 SKILL.md 阶段 C 的操作细则，不独立成立。

## 一、八步操作法

| 步 | 操作 | 关键问题 |
|----|------|---------|
| ① | 写出一句话故事机制 | 真正让人被卷进去的机制是什么？（不是设定，是核心一条） |
| ② | 找出八种受力位置 | 谁承受/谁控制/谁被排除（失落）/谁付代价/谁维护/谁知道来历/谁是人形化（象征）/谁让读者看见日常（显影）——先列人，不急着分好坏 |
| ③ | 确定主角 | 不是最惨的人，是**最能把问题推下去的人**：机制压到谁身上最能变成故事？谁一行动就牵动世界/关系/真相/代价？ |
| ④ | 配第一圈人物（三助一压） | 同路者（陪他走，让他在关系中显形）/ 带路者（让他进入世界、理解规则、获得方法）/ 支撑者（资源、证据、身份、庇护、情感、力量）/ 直接压力者（逼他受挫、选择、成长、付代价）——不必配满，但主角太顺太孤太工具时回看缺了什么 |
| ⑤ | 判断孰敌孰友 | **机制位置 ≠ 故事阵营**：承受者可以是反派，控制者可以是盟友，知情者可以是隐瞒者，维护者可以是动摇者。重问：谁站主角这边/谁阻止/谁利用/谁先敌后友/谁先友后敌/谁目标一致方法冲突/谁方法一致目标冲突 |
| ⑥ | 点连成网（九问） | ①彼此认识吗 ②谁欠谁 ③谁怕谁 ④谁保护谁 ⑤谁误会谁 ⑥谁曾经是同伴 ⑦谁现在站在不同边 ⑧谁的死亡会改变另一人的位置 ⑨谁的选择会牵出下一批人 |
| ⑦ | 长篇递归 | 总机制→主线人物；篇章机制→篇章人物；地区机制→当地人物；组织机制→势力内部人物；个人机制→关系人物。一层一层长出来 |
| ⑧ | 合并、升格、删除 | 功能重复的合并；一人多位值得升格；一次性功能做龙套；不改变选择也不改变压力的删。**人物越少，位置越准** |

**位置会挪移**（人物篇第二章「七」）：写着写着人物会变重或失效——先判断"他变重以后故事是不是更强？是否让主角选择更难？是否让主题更具体？"，变强就给位置，失焦就收束。

## 二、五组问题清单（完整表单）

> 38 问。**空答即人物未建立（质量门 1）**。每人一份，重要角色必填，配角至少填私+执。
> 填写要求：每个问题一句话以上、必须有载体（可拍的行动/物件/场景），"不知道""还没想好"= 空答。

### 1. 私九问（第三章：人物以什么为"我"）

```
人物：______

私-1  这个人物以什么为"我"？（什么被纳入自我边界，碰它等于碰存在）
私-2  他的欲望是什么？他表面上想要什么？（表面与真面不必一致）
私-3  他觉得自己缺乏什么？（主观匮乏，不等于客观事实）
私-4  他拼命保护、不愿失去的是什么？
私-5  他准备用什么手段去取得自己的目标？
私-6  他害怕什么？不愿意被人看到什么？
私-7  他的内心尺度是什么？什么东西能让他马上 get，什么东西他完全 get 不到？
私-8  他给自己的私找过什么借口？如何把自己的私说成合理？（"为了家人"外壳——何时开始需要这个理由）
私-9  他的私的范畴有变化吗？（边界扩张或收缩：谁从"自己人"变成"敌人"）
```

### 2. 处九问（第四章：天·地·人——他一开始背着什么）

```
人物：______

处-1  他从什么家庭来，有什么禀赋，又生在什么时刻？
处-2  他一开始背着什么期待、限制、债务、血统、天赋或时代压力？
处-3  他此刻在哪里？他能去哪里，哪里到不了？（活动范围）
处-4  他所处的局部环境怎样运行？这里奖励什么，惩罚什么，默认什么？
处-5  他知道什么，不知道什么，误以为什么？谁在瞒他，谁在误导他？
处-6  他手里有什么资源，又缺什么资源？他误以为什么资源可以解决一切？
处-7  这具身体让他能做什么，不能做什么？别人先把他看成什么？
处-8  哪个幽灵时刻塑造了他的心理底色？它让什么东西反复刺中他？
处-9  他被当成谁？被哪些关系牵住？他一动，会牵连谁？
```

### 3. 执七问（第五章：他抓住的旧答案）

```
人物：______

执-1  他抓住的旧答案是什么？它曾经怎样帮过他？（执有用过——这是他信的原因）
执-2  这个答案曾经给过他什么奖励？他又犯过哪些可以被解释的小错？（奖励与小错如何加固执）
执-3  他最不愿别人看见的羞耻是什么？他怎样遮住它？
执-4  他相信什么理，守护什么物，拒绝什么事，愿意付什么代价？（尺度与底线四问）
执-5  这个执现在显出什么形态？（正执/偏执/旧执/邪执）——并记录：它从什么形态变来的？（阶段变化，质量门 2）
执-6  谁最能让这个执显形？（敌人/盟友/亲人/被保护者/受害者/自己造成的后果）
执-7  如果他要改变，必须重新承认什么？改变成本是什么？（为什么不肯松手）
```

### 4. 为七问（第六章：行动现场）

```
人物：______

为-1  这一场里，他想要什么？他要拿到、避开、证明、保护或隐瞒什么？
为-2  什么压力让他不能轻易得到？（规则/他人/时间/资源/身体/关系/信息/道德代价——压力来自哪类）
为-3  他准备用什么计划去取？第一反应是求、争、忍、逃、控、藏、说、不说、硬撑、讨好、交换、安排，还是放手？
为-4  他有什么能力？这个能力解决了什么，又制造了什么代价？它有没有替人物逃避本该面对的选择？（质量门 9：无新行动方式 = 心理旁白）
为-5  他怎样命名现实？他说话、评价、解释和自我辩护的方式，暴露了什么执？
为-6  他的内在怎样外化？有什么动作、姿态、道具、沉默、身体反应或反复出现的小习惯？（源头即外化——原创流不做转译）
为-7  他行动之后，谁的位置改变了？谁靠近/离开/受伤/看清他/替他付代价？哪个日常从此回不去了？（行动涟漪，质量门 7）
```

### 5. 已六问（第七章：不可逆的终点）

```
人物：______

已-1  故事之后，他最后成了什么？承担了什么，挣脱了什么，剥离了什么，新生了什么，被什么吞噬，又抵达了怎样的新平衡？（六方向各问一句）
已-2  他的命运是完成，还是未竟？线是闭合了，还是留下一个继续影响别人的空缺？（"未竟"允许存在）
已-3  他的意义如何显出？他是否终于被重新理解？
已-4  他的选择是否回来结算了他？他一路的为，最后有没有回来定义他？（显露与结算）
已-5  结尾和起点形成什么关系？（闭合/反讽/加深/破裂——质量门 10 开头名/结尾名对照：证明/推翻/重铸/反讽）
已-6  他哪里真正回不去了？（无答案 = 命运未发生，质量门 8）
```

### 五层互验（生成顺序与回查）

顺序：私 → 处 → 执 → 为 → 已。回查规则：
- 私立"我"，处立"处境"，执立"答案"，为立"现场"，已立"不可逆"
- 执的七问必须与私的 1/6/7 一致（他抓住的答案由他的"我"和恐惧长出来）
- 已的六问必须由为的 7（涟漪）累积而成——终点不是贴上去的，是走出来的

## 三、执四形态（质量门 2/3）

| 形态 | 本质 | 写法要点 |
|------|------|---------|
| 正执 | 抓住一个值得守的原则（守信/守义/守真相/守底线/守人性） | 未必轻松——世界不断逼他松手；故事可写"如何守住"而非"如何放下" |
| 偏执 | 里面有真东西，只是尺度偏了 | 最有戏——不是纯错，读者能理解；故事不急着说他错，让它走进关系、代价、别人的痛苦里自己显出伤害 |
| 旧执 | 过去靠它活下来，后来被它困住 | 问题不在它从来没对过，恰恰在对过；故事让人物遇到旧答案解决不了的新局面 |
| 邪执 | 拿道理遮住私欲 | 很会说话——借正义/责任/牺牲/爱与保护的词；不能只写嘴上显坏，要写他做事：让谁付代价、遮住谁的痛、把谁从人变成材料 |

**阶段变化记录**：正执可失度成偏执，旧执可被修正，偏执可因羞耻和利益慢慢变成邪执——质量门 2 要求记录每个角色执的形态变化轨迹。

**执代价落点（质量门 3）**：
- 代价落自己 = 悲壮（可接受）
- 代价落别人 = 危险（需要显形）
- 代价落无辜者 = **伤害必须显形**——谁受伤、怎么受伤、他看见没有；"为了大局他们可以死"触发红牌，必须回 C 补显形载体

## 四、万用能力矩阵（番外「能力」）

> 理论核心表，完整引用自《人物篇》。设计能力不从外壳（火球/读心/重生/系统）开始，从欲望开始：**能力，是欲望获得特殊权限后的形状。**

核心欲望八类 × 正反合三方向：

| 欲望 | 正：满足欲望 | 反：威胁欲望 | 合：转化欲望 |
|------|------------|------------|------------|
| 生 | 治愈、护盾、续命、复活、自愈 | 毒、诅咒、腐蚀、死亡标记、生命夺取 | 转生、替命、共生、亡灵契约、以死换生 |
| 逸 | 恢复、避难空间、自动化、减负、无痛 | 疲惫、迟缓、痛觉放大、负重、剥夺睡眠 | 时间暂停、梦境休养、精神分身、身体托管 |
| 乐 | 幻觉、愉悦、味觉增强、情绪调节、游戏化 | 剥夺快感、痛苦转化、成瘾、恐惧放大 | 苦乐互换、痛感燃料、情绪炼金、狂欢领域 |
| 和 | 魅惑、共情、治疗关系、召唤同伴、心灵链接 | 分裂、孤立、仇恨放大、记忆篡改、背叛诱导 | 群体意识、契约关系、命运绑定、共享伤害 |
| 权 | 强化、支配、控制、命令、领域、规则权限 | 削弱、封印、剥权、缴械、反控制 | 权限交换、规则制定、阶层跃迁、系统管理员 |
| 变 | 变身、进化、适应、拟态、成长加速 | 退化、畸变、失控变异、身份错乱 | 多形态、自我重写、路线选择、从怪物中保持人 |
| 名 | 声望加成、身份伪装、称号、被记住、真名魔法 | 抹名、污名、遗忘、身份剥夺、替罪 | 改名换命、名实互换、传说化、以名召唤 |
| 道 | 预知、悟性、真相识别、规则洞察、因果感知 | 迷障、误导、假预言、认知污染、因果遮蔽 | 悟道、改写规则、见众生线、以认知改变世界 |

**用法**：不要机械选技能。同一外壳可服务不同欲望——读心满足理解别人是和之正，满足掌控别人是权之正，满足看穿真相是道之正。每个能力回答三句：
1. 它真正服务哪一种欲望？
2. 它在满足、威胁、还是转化这个欲望？
3. 人物缺口（私）为什么让这个能力有重量？

## 五、扑街十问（质量门 4，可勾选诊断）

```
人物/能力：______
[ ] 1. 能力有没有接住人物欲望？（主角缺什么、想补什么——为什么"终于有办法了"）
[ ] 2. 爽点是否具体？（越级/信息差/规则杀/打脸/经营/捡漏/收集/禁忌知识/身份跃迁——只有"变强"会空）
[ ] 3. 能力在场景里有没有手感？（怎么用/怎么触发/什么画面/别人怎么反制/留下什么痕迹——没手感=百科）
[ ] 4. 能力有没有限制？（无限制=替人物逃课）
[ ] 5. 代价是不是真的？（只吐血/睡一觉/耗体力而不改变人物关系和局面=装饰）
[ ] 6. 重要角色有没有异常？（公共体系可共用，重要角色要有自己的异常接口/偏用方式/代价承受）
[ ] 7. 能力有没有放大人物的执？（相信"求人没用"的人得到单人碾压能力，应更难学会求助——无反应=外挂）
[ ] 8. 升级有没有打开新处境？（新地图/新敌人/新组织/新资源/新身份/新限制/新历史债务/新道德问题——只是攻击力更高会疲劳）
[ ] 9. 使用能力以后有没有涟漪？（谁开始怕他/想利用他/误解他/受伤/发现秘密/哪条路从此关上——无涟漪=一次性烟花）
[ ] 10. 能力是否服务题材循环？（系统流要有任务奖励惩罚阶段目标；重生流要有信息差和遗憾修正；诡异流要有规则禁忌污染代价……）
```
