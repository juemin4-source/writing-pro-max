# 03 — 结构期（D 阶段操作细则）

> **理论来源**：本文件全部方法论出自用户自著《命运篇》：十二节点（第三章）、二十四节气验收句（第三章 5-9 节，验收句为理论核心，逐条引用原文）、失候清单（第一章与四季"整体"节）、叙事周期与信息分配（第二章）、叙事入口（第五章，入口细则见 00-seed.md）、大中小周期（第四章）、盆景七问（第七章）、章纲与大纲写法（第三章末尾）。"同一件事，早一点是解释，晚一点是拖延，放准了才是命运"——本阶段的核心是判断时位（火候）。
>
> 本文件是 SKILL.md 阶段 D 的操作细则，不独立成立。

## 一、命运大纲十二问

一条命运线从藏到归藏的十二个时位（也是检查"现在这件事在什么时位"的尺子）：

| # | 节点 | 时位问题 |
|---|------|---------|
| 1 | 藏 | 问题藏在哪个旧局里？ |
| 2 | 生 | 新势从哪里冒出？ |
| 3 | 将动 | 裂缝如何逼近？（事情还没发生，但已经快了） |
| 4 | 动 | 事情如何正式发动？ |
| 5 | 长 | 什么开始增长？（力量/关系/欲望/误解/代价） |
| 6 | 将育 | 增长出来的东西如何互相勾连、组局？ |
| 7 | 育 | 局面如何育成？ |
| 8 | 止 | 盛极处出现什么停顿和反力？（原来的路走到头了） |
| 9 | 将杀 | 旧答案如何进入清算前夜？（刀还没落，脖子已经凉了） |
| 10 | 杀 | 哪条旧路被斩断？（会改变故事地形） |
| 11 | 归 | 意义如何归位？（选择、代价、结果意味着什么） |
| 12 | 将藏 | 结果如何沉入下一轮？（成为新土壤） |

十二节点不是十二等分——有的节点一场戏，有的节点一整卷。它不要求按表填情节，只用来判断时位：该藏还是该动，该放还是该收。

## 二、二十四节气验收句（24 条）

> 逐场/逐幕可判（质量门 12）：写到任何一段，问"这条线现在在什么节气"，用对应验收句对照。验收句为《命运篇》理论核心原文提炼，保留原术语。

### 冬·开头（故事承诺藏在旧局里）

**1. 冬至（雪下有动）**
验收句：*这条命运线在显出来以前，是否已经有了暗动？*
- 不急着讲创伤、不解释人物为何如此——只要让他的活法出现（怎样开门、怎样说话、怎样沉默、怎样避开某个名字、怎样把一个不正常的状态过成日常）
- 最好的冬至：读者还不知道答案，却已经感觉雪下不平。暗动说得太明，冬就散了

**2. 小寒（冷意刺进来）**
验收句：*旧局有没有开始发冷？*
- 写的不是崩塌，是旧答案开始不好用了：沉默仍然维持和平，可这次沉默让人受伤；控制仍然带来安全，可安全感越来越少
- 小寒要冷意刺进来，但门还没彻底破——没寒意后面改变会突然，直接爆开又抢走春的位置

**3. 大寒（冰面将裂）**
验收句：*这条命运线为什么已经走到转相之前？*
- 冰面已硬到发声：之前可以拖，现在拖不下去；之前可以忍，现在忍的代价变了
- 不写成爆发（爆发留给立春）——只要让人感觉"这件事不可能永远藏着"

### 春（承诺怎样从旧局里冒出来）

**4. 立春（旧冰初解）**
验收句：*事件有没有打到旧局的冰面？*
- 最怕"事件很大，人物没动"——事件要打到人物的私和执：他怕什么，事件就碰到什么；他依赖什么，事件就让那东西开始失灵

**5. 雨水（水气渗开）**
验收句：*世界开始有回声了吗？*
- 事件渗进关系、渗进环境、渗进旁人的判断：一个人说了一句话，另一个人开始重新看他；一个消息传出去，外部世界开始回应
- 春天不能只有主角动——只有主角遇事、身边人像没被影响，故事会窄

**6. 惊蛰（伏着的东西被雷惊醒）**
验收句：*新局面里有他想要的东西吗？*
- 变化进入人物身体里：被吸引、被召唤、开始害怕也想靠近
- 如果春只有压力，人物就只是被剧情推着走；如果春只有麻烦，故事就像受难清单
- 这里常常出现一个敲门的人（不一定是导师）——他的作用是让人物不能继续睡

**7. 春分（新旧对半）**
验收句：*旧答案如何反扑？（倒春寒有没有来）*
- 旧关系挽留他、旧身份提醒他、旧恐惧吓住他、旧世界告诉他"你现在回头还来得及"
- 没有春分，人物变化太顺——太顺，旧局就没有重量，后面的成长也变假。真人在看见新路后仍会把旧壳带进春天

**8. 清明（雾气散开）**
验收句：*读者看清主局轮廓了吗？*
- 不是全部真相大白，是雾气散开一层：主线和暗线关系清楚，规则开始变成行动条件（谁能进去谁进不去、什么能交换什么不能碰）
- 清明不是解释设定——设定压不到人物身上仍然不清

**9. 谷雨（春水养足）**
验收句：*短期目标打碎、长期目标锁住了吗？*
- 人物发现短期目标不够用（事情比想象中深、原来想保住的旧生活保不住了）；窗口打开（新证据/真正敌人露面/组织发出命令）
- 到了谷雨，人物还不能退回冬——春水已经把他养到必须往前长

### 夏（承诺怎样生长成局）

**10. 立夏（新局开门）**
验收句：*新世界活起来、人物产生主动性了吗？*
- 春是看见门，立夏是真正进门：新规则压到人身上、新空间带来新行动
- 立夏要有甜头（资源/能力/情感连接/身份感/真相线索/胜利体验）——没有甜头，人物为什么继续往前？但这个甜头最好同时带着后面的账

**11. 小满（未满之满）**
验收句：*每个爽点都开始记账了吗？*
- 甜头带出苦味：赢了一次吸引更大敌意、越过一条规则欠下后债、看见一点真相误以为理解全局
- 小满还淘汰脆弱的东西（漂亮但无根的幻想开始枯）；不是大满，山还在远处

**12. 芒种（因果落种）**
验收句：*行动开始产生后果了吗？*
- 今天相信谁、放过谁、隐瞒什么、破坏哪条规则——后面都会收
- 巧言失效：解释、调和、逃避、漂亮话不能再糊弄过去，人物必须做选择；支线、误会、敌意开始真正咬住主线
- 芒种不是高潮，是因果落进土里——秋天收割什么，在这里种下

**13. 夏至（盛处照裂）**
验收句：*最亮处，裂口被照出来了吗？*
- 人物最有希望时副作用出现、关系最亲近时真实需求显形、组织最强盛时底层逻辑暴露
- 夏至不一定是失败，甚至可能是胜利——但这场胜利里要露出伤；没有照裂，后面的反噬没有根

**14. 小暑（旧债反咬）**
验收句：*压力变成近身感了吗？*
- 前面欠的人情、破坏的规则、放过的人、误信的盟友开始逼到眼前；活动空间变窄（能躲的地方不能躲）
- 不是最后一刀，是旧债反咬的开始：夏天长出来的不全是果实，也有藤蔓缠住脚踝

**15. 大暑（群线并网）**
验收句：*各线并网了吗？*
- 主线、支线、关系线、反派线、秘密线要开始并网；从坏掉的地方长出可用之物（废墟里出现线索、失败里生出新理解）——希望从腐败里来，带着味道
- 局面变得黏滞：救一个人得罪另一个人、拿到线索暴露身份；最好有一次暴雨式事件把各线冲到一起

### 秋（承诺怎样接受检验）

**16. 立秋（凉意初至）**
验收句：*增长降温了吗？*
- 夏天所得（能力/关系/线索/身份/债务/伤口）转向真正难题；支线向主干靠拢；爽点显出它的账
- 不是秋杀，只是告诉故事：不能再这样长了

**17. 处暑（猎场验收）**
验收句：*夏天所得真的有用吗？*
- 秋老虎——"好像还能赢"；要承认所得是真的（不能让夏天白长），但虚胖同时暴露（阵营有裂缝、胜利只是引出更大敌人、还差最后一个不能逃的判断）
- 不是最终失败，是最后清算前的一次试刀：所得有用，但不够

**18. 白露（各归其位）**
验收句：*人物、关系、筹码回到场上、各就各位了吗？*
- 支线人物回到场上、关系和阵营开始站定、关键筹码集中、该回来的回来
- 暧昧空间变小：人物不能永远既要又要、秘密不能永远只藏在暗处
- 没有白露，秋分就会轻——刀要落，先要让东西各在其位

**19. 秋分（分判落下）**
验收句：*混在一起的东西被切开了吗？（旧暧昧状态是否结束）*
- 真相和假象分开、爱和逃避分开、责任和自保分开、盟友和敌人分开——原本保留的退路，要断掉一条
- 最怕写成大场面：没有分判，场面再大也不是秋分
- 刀落之后，故事的空气会变冷——分开，就意味着失去（质量门 16 复核点）

**20. 寒露（冷中见果）**
验收句：*结果压到人身上了吗？*
- 胜利/失败/真相/告白/牺牲不能只"发生了"——要改变主体的身体、身份、处境、信念或行动空间
- 一个人赢了，却再也不能回到原来的关系里；一个敌人倒下了，却把更大的空洞留给世界
- 刀不是落在事件上，而是落在人身上

**21. 霜降（枝叶尽落）**
验收句：*落叶之后看见枝干了吗？*
- 假目标、假关系、假答案、旧身份、逃避路线、虚胖支线落下——但不必都写一遍，故事要有"落叶之后看见枝干"的清楚
- 新状态开始固定：人物新状态、关系新位置、世界新秩序、伤口进入稳定状态
- 霜降不是结尾，是归藏的入口

### 冬·结尾（承诺怎样归入新的旧局）

**22. 立冬（结果固定）**
验收句：*结果进入现实了吗？*
- 规则变了要看见新规则怎样运转、身份变了要看见人物怎样带着新身份生活、关系变了要看见两人再见面时位置已不同
- 旧物换形：敌人死了，但他的逻辑还留在制度里；旧伤不再支配人物，却变成他理解别人的能力
- 门重新关上，但门后已经不是原来的房间

**23. 小雪（新旧分层）**
验收句：*新日常覆盖旧痕、雪下并不平吗？*
- 新旧一层压一层：人物已改变但旧习惯留痕迹、关系已重定但旧亏欠不消散
- 最怕纯说明（某人去了哪里/终于明白了什么——这些可以写，但不能只有这些）
- 矛盾开始酝酿：今天的胜利可能藏下新的代价——不是马上开启新主线，只是让读者知道新日常也会慢慢变成新的旧世界

**24. 大雪（喧闹落幕）**
验收句：*余震留在雪下了吗？*
- 不是所有情绪都要继续喊、不是所有伏笔都要当场拆开；有些问题不必再追，它会在读者心里继续响
- 不是死寂：暗处仍有新问题（一段没彻底说开的关系、一个被雪盖住的痕迹、一个旧制度留下的缺口）
- **大雪最重要的，不是制造续集钩子，而是保留余震**——让读者看见足够多的轮廓，也让一些东西沉到雪下

## 三、失候清单红线扫描（质量门 13：6+2+5+4+2）

> 机械可勾选（六类各条可判定"是/否"），命中即 WARN 或 FAIL。

**6 条时位失候**（看不清时位的常见问题）：
```
[ ] 该藏的时候说太多 → 读者失去追索感
[ ] 该动的时候还在铺垫 → 故事迟迟发动不了
[ ] 该长的时候没让关系/势力/误解/代价真正长起来 → 高潮没重量
[ ] 该杀的时候舍不得断 → 结局软
[ ] 该归的时候只顾反转 → 意义回不到人物身上
[ ] 该将藏的时候把话说尽 → 没有余震
```

**2 条春失候**：
```
[ ] 春不发：铺垫很多、犹豫很多、解释很多，但冰没有松、水没有渗、人物没有醒、主局迟迟不显
[ ] 春太顺：事件一来立刻成长、召唤一到旧答案立刻失效、新世界一开所有东西都像为主角准备好
```

**5 条夏虚胖失候**：
```
[ ] 世界很大，但没有规则压人
[ ] 人物变强，但没有代价记账
[ ] 关系升温，但没有真实需求显形
[ ] 支线很多，但没有并入主干
[ ] 场面很热闹，但没有裂口
```

**4 条秋失候**：
```
[ ] 到了秋还在加枝叶 → 故事散
[ ] 到了秋还舍不得分判 → 高潮软
[ ] 到了秋只有热闹没有冷意 → 结果轻
[ ] 到了秋只写事件不写承受 → 人物不变
```

**2 条结尾冬失候**：
```
[ ] 停得太早：秋分刚落刀故事立刻结束——事件有结果，人物却没有新常态
[ ] 说得太尽：意义/后续/人物去向/伏笔解释得干干净净——雪还没落下来，地已经被扫空
```

## 四、叙事大纲（六项判断）

| 判断项 | 操作 | 说明 |
|--------|------|------|
| 情绪承诺 | 承诺什么情绪？ | 悬疑/爽感/心动/恐惧/成长/悲剧/史诗/荒诞——入口与信息分配都随它定 |
| 叙事主体七选 | 主要截取谁的命运？ | 主角的 / 群像的 / 案件的 / 组织的 / 时代的 / 世界的 / 认知的——七选一 |
| 截取范围 | 从命运的哪里开始、到哪里结束？ | 正文可以按命运顺序写，也可以从春/夏/秋/归藏入（叙事周期 ≠ 命运周期） |
| 开头/结尾 | 怎么进、怎么收？ | 开头决定第一脚，结尾决定离开时的回声 |
| 主要问题 | 观众追什么问题？ | 与悬念五类（00-seed）一致，是 logline 的观众侧 |
| 信息分配七种 | 七选一 + 一致执行 | 见下 |

**信息分配七种**（质量门 17：七选一 + 一致执行）：
1. 顺叙——读者跟人物一起经历（稳定清楚，成长向）
2. 插叙/倒叙——结果先出现再回头追问（创伤/悬疑/秘密/命运回望）
3. 多视角——同一件事在不同人物眼里不同形状（群像/政治/战争/复杂组织）
4. 误解——人物或读者用错误答案暂时解释世界（悬疑/悲剧）
5. 读者知道的比人物多——悬念与命运感（读者看见灾难逼近，人物还在旧日常里→痛感）
6. 人物知道的比读者多——神秘感与压迫感（人物做奇怪选择，后面才发现他早承受了真相）
7. 不给完整答案——余味（看到轮廓，知道下面有东西，不把每块冰都挖出来解释）

> 同样一段命运：顺着讲是成长，倒着讲是追悔，多视角讲是局势，误解着讲是悬疑，读者多知一点是悲剧，人物多知一点是谜，不给完整答案是余味。

## 五、时位细纲

```
三线节点：
  主角线：节点列表（每个节点标注节气 + 时位）
  盟友线：节点列表
  反派线：节点列表

支线"将"位接入（质量门 14）：
  将动 ← 支线推主线发动（配角的求救/旧关系来信/支线异常让裂缝逼近）
  将育 ← 支线与主线组局（支线人物带来的信息改变主角判断）
  将杀 ← 支线把代价送回主线（配角线里的牺牲逼主角做选择）
  将藏 ← 支线把余波沉入下一轮（活下来的配角带伤口进入下一轮）
```

支线最好的接入位置不是正节点，而是"将"——主线在正节点显形，支线在"将"里接入。支线太早抢前台会遮住主线；高潮时所有线突然并起，读者只觉得热闹，感觉不到命运合流。

## 六、大中小周期对齐（质量门 15）

| 层 | 是什么 | 对齐检查 |
|----|--------|---------|
| 全书周期（大） | 作品最大的命运形状，主气候（春/夏/秋/冬） | 全书是春时，支线不能霜降 |
| 卷/区域周期（中） | 卷、副本、案件、地图 | 主线入秋时，支线不能还在春花 |
| 人物/支线周期（小） | 单个人物、一段关系的四季 | 主角已夏至时，反派不能才立春 |

原文四组对照：主线入秋支线不春花 / 主角夏至反派不才立春 / 世界线霜降某段关系不到雨水 / 卷尾归藏全书不才小满。部分要含着整体的气——部分不是孤立零件。

## 七、盆景七问（质量门 19）

| # | 问 | 判定要点 |
|---|----|---------|
| 主景 | 主线是否精彩？ | 主线不是"发生最多事情的线"，是承载故事承诺的线；主景要有势（从冬藏走到归藏）。主线无力，设定/反转/场面都救不了 |
| 辅景 | 是否让主线更有层次，而不是喧宾夺主？ | 判断辅景能不能留，不看它好不好看，看它有没有让主线更有层次（加深主角选择/主题多一个角度/把代价送回主线） |
| 对景 | 支线之间是否产生互文？ | 一个小人物的命运提前演示主线未来的代价；三线回应同一问题，主题不靠说明自己显出来。对景最怕孤立 |
| 借景 | 可延展性如何？ | 让读者感觉正文之外还有世界。借景不是挖坑（挖坑是留未解谜题等以后再填）；借景是让故事有远处 |
| 路径 | 读者怎样穿过故事？ | 他什么时候进入/被吸引/产生疑问/误解/恍然/紧张/喘气/被推向下一章——设计路径是管理读者的心态 |
| 疏密 | 结构有呼吸吗？ | 高潮要密、群线并网要密；但人物需要喘气、读者需要消化、关系需要留白。一个安静场景可以让下一场爆发更疼 |
| 藏露 | 水下的必须影响水面 | 藏是保留深度，露是给读者抓手；**水下的东西必须影响水面**——不影响水面 = 作者私设，删（质量门 20） |

## 八、章纲七要素（质量门 18，场/幕级验收卡）

每章/每场验收（机械可查字段是否齐全）：

```
[ ] 视点        这一章/场的镜头主语是谁？
[ ] 发生什么事   核心事件（一句话，可拍）
[ ] 人物动机     他为什么做这件事？（不是剧情需要他做）
[ ] 阻力        什么挡在目标和结果之间？（具体可拍，不是"命运"）
[ ] 变化        人物状态从 X 变成 Y（无变化 = 这场戏为什么存在？）
[ ] 释放或隐藏什么信息   观众获得/被扣住什么信息？（与信息分配七选一致）
[ ] 钩子        结尾把读者推向哪里？
```
