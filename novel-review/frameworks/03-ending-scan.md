# 03 — 结局层诊断表（《命运篇》归藏 + 《天演论》余震）

> **理论来源**：用户自著《命运篇》第三章「9.冬」（大雪/冬至/归藏）与《文学天演论》（"结尾没有余震，便只是停止"；"真正的余震不是留坑，余震是意义没有耗尽"；"余震来自前面所有不可逆变化"）。检查项复用 `novel-original-writing/frameworks/06-ending.md`——**只引用路径，不复制内容**。
>
> 本文件是 SKILL.md「层 3：结局层扫描」的操作细则，不独立成立。

## 诊断流程

```
1. 大雪 gate 四查 → 2. 冬至 gate → 3. 归藏三查 → 4. 余震三问 → 5. 跨层不可逆复核
```

## A. 大雪 gate（四查）

```
1. 喧闹落幕：结尾不再喊/不解释尽/不逐人总结？           落幕 / 未落幕
   → 证据：结尾段____
2. 问题不追尽：有"不必再追但会在读者心里响"的东西？     有 / 没有
3. 雪下留痕：暗处有未打开的新问题（关系/痕迹/缺口）？   有 / 没有
4. 余震 vs 钩子：结尾留的是"命运没被用完"还是"续集预告"？余震 / 钩子
   → 钩子证据：结尾是不是在介绍新冲突/新人物/新任务？
→ 未落幕 = 红牌；追尽 = 红牌；写成钩子 = 红牌；无留痕 = 黄牌
```

## B. 冬至 gate（如有暗动）

```
结尾暗动（如存在）：____
动得够小吗？（水泉在冰下动 vs 掀开大雪盖住的东西）      够小 / 太大
→ 太大 = 红牌（归藏被破坏，结尾变成新一轮开场）
```

## C. 归藏三查

```
1. 新常态入日常：结果进入现实了吗（规则/身份/关系/生活方式变了）？  是 / 否
   → "不是后来怎么样，是结果已经进入现实"
2. 关系结霜：谁还能站一起/谁不能回头/谁欠谁——有明确新状态？      是 / 否
3. 未耗尽问题：故事结束但问题还在（不必追但会响）？                是 / 否
→ 任一否 = 黄牌；全否 = 红牌（结局只是事件交代）
```

## D. 余震三问（《天演论》）

```
1. 读者无法轻易完成判断吗？（人物真的错了吗/胜利会不会变坏…）  能 / 不能
2. 人物承受观点后留下复杂性吗？（不是传声筒）                   是 / 否
3. 结尾是余震还是解释清楚？                                    余震 / 解释
→ 3 问 2 否以上 = 红牌（"读起来很正确，却没有余震"）；1 否 = 黄牌
```

## E. 跨层不可逆复核

```
1. 人物层"已-6（哪里回不去了）"在结局有对应画面/事件吗？       有 / 无
   （人物层结论引用：01-character-scan.md 结果）
2. 结构层"秋分断掉的退路"没有被偷偷接回？                      没有接回 / 被接回
   （结构层结论引用：02-structure-scan.md 结果）
→ 无对应画面 = 红牌（不可逆只存在于设定）；退路被接回 = 红牌（秋分失效）
```
