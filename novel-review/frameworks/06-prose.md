# 06 — 文笔层诊断表（《文学天演论》第六部·现场八查）

> **理论来源**：用户自著《文学天演论：人物、命运与余震》第六部「现场：如何把大纲写成正文」（导论 + 定势/物色/身位/声口/章句/情采/风骨/熔裁八章，各章均有"五个问题/检查"小节）。
> 本表把八章的可判定检查转成"从文本找证据"的诊断形式——**只引用路径与检查项，不复制正文**。
> 本文件是 SKILL.md「层 3.5：文笔扫描」的操作细则，不独立成立。

## 一、现场的定义（第六部导论）

> "如何把故事的时位，写成纸面上的现场。"
> 场景不是背景 / 物件不是道具 / 对话不是说话 / 文采不是漂亮 / 删改不是变短 / 结尾不是总结——**它们都是让命运显形的方法**。

判断文笔不判"好不好看"，判**时位有没有落成现场**：一个人失去童年，不写"他失去了童年"，写那只碗从手里飞出去，在水面上漂远。

## 二、诊断流程

```
1. 抽取 3-5 个关键场面：1 个动作场面（战斗/追逐/抉择）+ 1 个对话场面 + 1 个重戏或结尾场面
2. 对每个场面跑现场八查（下），每条结论带原文证据
3. 汇总：八查过/半过/不过数 → 文笔层结论
```

证据纪律同 00-scan.md §二：每条问题必须带原文引用 + 定位；反推不动 = 该查不过。

## 三、现场八查（每查：检查项 → 判定 → 证据）

### 查 1：定势（第六部·第一章）
**检查项**：写这场戏先明位再定势——
- 位：此时何时 / 此人何人 / 此地何地 / 此关系走到哪里 / 此句位于全篇何处？
- 势：这场戏是出发、补救、对峙、裸露、相变还是归藏？
- **判定**：文字在解释背景而非明位 = 不过（"位不明，势必浮；势不定，笔必散"）；"先问这段要不要感人、这句要不要漂亮" = 势未定

### 查 2：物色（第六部·第二章·物色五问）
**检查项**：写完一件物问五问——
1. 它的第一重功能是什么？（只剩象征没有功能 = 虚）
2. 谁碰过它？（没有人的手 = 没温度）
3. 它经历了什么动作？（看见/得到/使用/藏起/损坏/遗失/追回/归还/焚毁——至少要有变化）
4. 它打在人物哪个缺憾上？（与人物无关 = 装饰）
5. 它回来时是否变义？（再次出现意义没变 = 重复）
- **判定**：5 问 ≥2 否 = 不过；1 否 = 半过

### 查 3：身位（第六部·第三章·身位五问）
**检查项**：写完一场戏问五问——
1. 谁在看？（视角太散 = 现场变成资料）
2. 他先看见了什么？（先看见什么暴露他怕什么、要什么、懂什么）
3. 他看不见什么？（盲区决定人物的真实）
4. 谁做了不可撤回的小动作？（不一定是大动作，但做完位置应该改变）
5. 谁看见了这个动作？（动作被看见 → 进入关系、误解、债务、余波）
- **判定**：视角无盲区或动作无后果 = 不过；"动作不是动作描写，而是选择落地"

### 查 4：声口（第六部·第四章·对话五问）
**检查项**：写完一段对话问五问——
1. 谁在争夺位置？（没人争位 = 只是在聊天，要问这段聊天是否真的需要）
2. 谁没有说真话？（人物通常不会把真话完整交出来）
3. 谁改写了问题？（能让对方按自己框架回答 = 占了上风）
4. 称呼有没有变化？（称呼变了关系可能已变；该变没变同样重要）
5. 说完之后，关系有没有移动？（没移动 = 这段对话可能只是信息）
- **判定**：对话 = 信息交换、人物回答得太完整 = 不过（"对话不是说话，是关系行动"）

### 查 5：章句（第六部·第五章·章句五查）
**检查项**：写完一段问五问——
1. 这一段的气从哪里起？（找不到起点 = 段落散）
2. 这一段推向哪里？（没有方向的铺排 = 堆砌）
3. 哪里该密，哪里该疏？（密处要有压，疏处要有寒）
4. 短句有没有落在骨点上？（短句太多 = 骨点就没有了）
5. 长句里有没有物和动作？（只有抽象词 = 长句空绕）
- **判定**：段无方向、长句空绕、密疏失衡 = 不过（"章句不是修辞问题，是场面呼吸问题"）

### 查 6：情采（第六部·第六章·情采五查）
**检查项**：写完一段有文采的文字问五问——
1. 这句话从哪里长出来？（找不到物、场、动作、关系 = 浮）
2. 这个比喻属于这个现场吗？（换到别的故事也一样成立 = 太泛）
3. 人物此刻有资格说这句话吗？（没有 = 作者在说）
4. 它是让读者更接近人物，还是更注意作者？（读者只觉得作者聪明 = 人物退后）
5. 删掉它，情会不会更准？（有些句子一删，情反而浮出来）
- **判定**：金句早来、比喻太泛、人物语言过高 = 不过（"人物不能替作者拥有过高的语言"）

### 查 7：风骨（第六部·第七章·风骨五查）
**检查项**：写完一场重戏问五问——
1. 人物的选择有没有代价？（没有代价 = 不要写得太重）
2. 我有没有提前使用大词？（牺牲、成长、命运、自由、救赎、绝望——是否来得太早）
3. 我有没有替人物解释得太多？（解释拿掉场面仍成立 = 就该拿掉）
4. 沉默处有没有被压住的话？（没有被压住的声音 = 沉默就是空）
5. 结尾是不是停得太晚？（很多场面多写了最后一句）
- **判定**：大词早用、替人物立碑、悲剧写满 = 不过（"大事小写""不要替人物立碑"）

### 查 8：熔裁（第六部·第八章）
**检查项**：回环变义 + 删解释 + 裁喜欢的句子——
- 回环变义：物/话回来时变义了吗？"第一次是日常，第二次带着关系，第三次带着伤，最后一次带着命，它才是回环"；一直日常 = 只是重复
- 删解释："删掉的是作者过度说明，保留的是读者理解所需的动作、物、场和关系"；"解释常常是尚未熔好的痕迹"；线索已够 = 解释多余；读者无线索 = 空白是偷懒
- 裁最喜欢的句子："它一出现，读者的注意力从人物身上转到作者身上" = 该删
- **判定**：把话说尽（解释未熔）、回环不变义 = 不过

## 四、文笔层严重度

- **文笔层不生成红牌**：红牌语义 = 违反理论硬规则（人物/结构/结局层），文笔无硬规则
- **黄牌**：文笔伤及可读性（读者无法理解发生了什么）/ 系统性缺陷（对话全为信息交换、场面全无物与动作、长句全抽象）/ 熔裁失败导致"说得太尽"
- **建议**：火候级（比喻可更准、气口微调、金句位置、某处可借物）
- **跨层记牌**：文笔问题同时构成理论问题时（声口空答 → 人物层为-5；熔裁失败 → 结构层"说得太尽"；视角换档 → 结构层信息分配），**记入对应理论层**，文笔层作为证据引用——一条问题不重复计牌

## 五、与天演评分互证（05-score.md）

| 评分参数 | 文笔层互证判据 |
|---------|---------------|
| η 叙事效率 | 章句（气口/疏密）、情采（金句早来=闲笔） |
| R 阅读阻力 | 身位（视角散=资料）、熔裁（解释未熔=堆砌） |
| ξ 作者怨念 | 风骨（大词早用/替人物立碑/解释太多=无余震） |
| M 奇观质量 | 物色（世界之物的功能与回环） |
| T 移情指数 | 声口（关系行动=理解他为什么这样说） |

## 判定边界备忘

- 文笔判断按作品自身承诺的类型标准判（喜剧的闲笔是风格，文学向的留白是风格——00-scan.md §四 同规则）
- 片段扫描：只对给定段落跑八查，不判全书文笔
- 大纲扫描：文笔层不适用（无正文），报告中标注"文笔层跳过"
