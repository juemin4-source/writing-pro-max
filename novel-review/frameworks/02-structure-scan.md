# 02 — 结构层诊断表（《命运篇》）

> **理论来源**：用户自著《命运篇》。诊断检查项复用 `novel-original-writing/frameworks/03-structure.md`（命运大纲十二问/二十四节气验收句 24 条/失候清单 19 条/信息分配七种/大中小周期/盆景七问/章纲七要素），本表把它们转成"从文本找证据"的诊断形式——**只引用路径，不复制内容**。
>
> 本文件是 SKILL.md「层 2：结构层扫描」的操作细则，不独立成立。

## 诊断流程

```
1. 先标注每主要叙事线的"当前时位"（节气），再逐项扫描
2. 失候清单 19 条逐条勾选（机械可做）
3. 盆景七问逐问对照
4. 汇总：失候命中数 + 各问结论 → 结构层结论
```

## A. 时位标注（先做）

```
主线：目前读到 节气____（对应验收句：____）
支线 1：____    支线 2：____    反派线：____
→ 对照验收句（novel-original-writing/frameworks/03-structure.md §二）：该线的实际写法
  与验收句是否吻合？不吻合 = 时位问题（黄牌起）
```

## B. 失候清单红线扫描（19 条，机械勾选）

```
时位失候 6：
[ ] 该藏的时候说太多 → 失去追索感
[ ] 该动的时候还在铺垫 → 迟迟发动不了
[ ] 该长的时候没让关系/势力/误解/代价长起来 → 高潮没重量
[ ] 该杀的时候舍不得断 → 结局软
[ ] 该归的时候只顾反转 → 意义回不到人物身上
[ ] 该将藏的时候把话说尽 → 没有余震
春失候 2：
[ ] 春不发（铺垫很多但冰没松水没渗人没醒主局不显）
[ ] 春太顺（事件一来立刻成长、召唤一到旧答案立刻失效）
夏虚胖失候 5：
[ ] 世界很大但没有规则压人
[ ] 人物变强但没有代价记账
[ ] 关系升温但没有真实需求显形
[ ] 支线很多但没有并入主干
[ ] 场面很热闹但没有裂口
秋失候 4：
[ ] 到了秋还在加枝叶（散）
[ ] 还舍不得分判（高潮软）
[ ] 只有热闹没有冷意（结果轻）
[ ] 只写事件不写承受（人物不变）
结尾冬失候 2：
[ ] 停得太早（事件有结果，人物没有新常态）
[ ] 说得太尽（意义/后续/伏笔解释得干干净净）
```

命中规则：任一条命中 = 红牌（失候是结构硬规则违反）；每条命中记录证据（哪一段）。

## C. 二十四节气抽查（关键段落逐条对照）

对关键幕/转折段做抽查，用验收句判火候：

```
抽查 1：段落____ → 对照节气____验收句 → 吻合 / 偏早 / 偏晚 / 缺要素
抽查 2：段落____ → 对照节气____验收句 → 吻合 / 偏早 / 偏晚 / 缺要素
抽查 3：段落____ → 对照节气____验收句 → 吻合 / 偏早 / 偏晚 / 缺要素
→ 偏早 = 该藏时露了（信息过早）；偏晚 = 该动时还在铺（节奏拖）
```

## D. 信息分配一致性

```
实际采用：顺叙 / 插叙倒叙 / 多视角 / 误解 / 读者多知 / 人物多知 / 不给完整答案
中途换档：是 / 否（换档点：____，换档有理由吗：____）
→ 换档无理由 = 黄牌（读者路径断裂）
```

## E. 大中小周期（多线作品）

```
对照 4 组：主线入秋支线不春花 / 主角夏至反派不才立春 / 世界线霜降某段关系不到雨水 / 卷尾归藏全书不才小满
错位：____（有设计理由：是 / 否）
→ 无理由错位 = 黄牌；错位且伤主线 = 红牌
```

## F. 盆景七问（逐问对照，出结论）

```
主景：主线立得住吗？（承载故事承诺、有从冬藏到归藏的势）   立得住 / 无力
辅景：支线/配角让主线更有层次，还是喧宾夺主？             有层次 / 抢景
对景：支线之间互文吗？还是各写各的孤立小树？              互文 / 孤立
借景：正文之外有世界吗？还是挖坑（留未解谜题等填）？      有远处 / 挖坑
路径：读者知道自己站在哪、追什么、为什么继续走吗？        清楚 / 迷路
疏密：有呼吸吗？（全满 = 每章都冲突都用力）                有疏密 / 太满
藏露：水下东西影响水面吗？不影响水面的私设多吗？          影响 / 私设堆积
→ 主景无力 = 红牌（树干不立）；其余各问命中 = 黄牌；藏露私设 = 黄牌
```

## G. 章纲七要素抽查（机械）

```
抽查 3 章：视点/事件/动机/阻力/变化/信息/钩子 各字段
→ 缺"变化"的章 = 流水账（黄牌）；缺 2 字段以上 = 黄牌
```

## 结构层汇总

```
失候命中：__ 条（红牌）    时位/节气问题：__    盆景问题：__    黄牌合计：__
一句话结论：<结构层主要问题：时位偏早偏晚/失候集中哪类/主景无力/疏密失衡…>
```

## 判定边界备忘

- 片段扫描只判局部时位，不判全书（见 00-scan.md §四）
- 大纲扫描：A/B/C 全做（对设计本身），D-G 按大纲能推断的部分做
