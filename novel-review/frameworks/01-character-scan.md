# 01 — 人物层诊断表（《人物篇》）

> **理论来源**：用户自著《人物篇》。诊断检查项复用 `novel-original-writing/frameworks/02-character.md`（五组问题完整表单/执四形态/万用矩阵/扑街十问），本表把它们转成"从文本找证据"的诊断形式——**只引用路径，不复制内容**。
>
> 本文件是 SKILL.md「层 1：人物层扫描」的操作细则，不独立成立。

## 诊断流程

```
1. 列出全部重要角色（≥2 次影响情节）
2. 逐角色做诊断表（下）
3. 汇总：空答数/红牌数/黄牌数 → 人物层结论
```

## 逐角色诊断表

```
角色：______

A. 五组问题可答性（从文本反推，推不出即洞）
   私 9 问：答出 ___ 问 / 9；推不动的：私-__（原因：_____）
   处 9 问：答出 ___ 问 / 9；推不动的：处-__（原因：_____）
   执 7 问：答出 ___ 问 / 7；推不动的：执-__（原因：_____）
   为 7 问：答出 ___ 问 / 7；推不动的：为-__（原因：_____）
   已 6 问：答出 ___ 问 / 6；推不动的：已-__（原因：_____）
   → 空答判定：重要角色空答 ≥ 5 问 = 红牌（人物未建立）；
              空答 2-4 问 = 黄牌；0-1 问 = 通过

B. 执的诊断
   执写得出来吗？（他抓住的旧答案是什么——文本能指认吗？）  是 / 否
   执有来路吗？（为什么信——曾经的帮助/奖励）               是 / 否
   执有形态吗？（正/偏/旧/邪 可指认，而非"他很固执"标签）   是 / 否
   执有阶段变化吗？（形态漂移/被检验）                       是 / 否 / 无需（短篇）
   → 执无来路或只有标签 = 黄牌；执完全写不出 = 红牌

C. 执代价落点（有执的角色必查）
   代价落自己（悲壮）／落别人（危险）／落无辜者（须显形）
   落无辜者时：伤害显形了吗？（谁受伤/怎么受伤/他看见没有）  是 / 否
   → "为了大局他们可以死"且伤害未显形 = 红牌

D. 行动涟漪
   关键行动后"谁的位置改变了"文本有对应吗？
   列出 3 个关键行动逐一查：______ / ______ / ______
   → 2/3 以上无涟漪 = 黄牌；全部无涟漪 = 红牌（人物在真空中行动）

E. 不可逆（已）
   "哪里回不去了"能指认吗？（关系/身份/能力/信念/日常层面）  能 / 不能
   → 主角不能 = 红牌（命运未发生）；配角不能 = 黄牌

F. 能力与执的互动（有能力的角色）
   能力服务哪种欲望（生/逸/乐/和/权/变/名/道 × 正反合）？   可答 / 不可答
   能力与执反应吗？还是外挂？                               反应 / 外挂
   能力有代价且代价真实吗？（改变人物/关系/局面 vs 只吐血）  真实 / 装饰
   → 外挂或装饰 = 黄牌（不阻断但弱）；能力完全游离主题 = 黄牌
```

## 人物层汇总

```
红牌：__ 条    黄牌：__ 条    建议：__ 条
一句话结论：<人物层主要问题集中在哪：空答/执无来路/涟漪缺失/不可逆缺失…>
```

## 判定边界备忘

- 配角（出现 <2 次且不影响情节）只扫 A 的私+执，其余不诊
- 群像作品：主角群每人全表；其余按戏份降级
- 反推不动的"问"必须记录**在哪一段推不动**（证据纪律，见 00-scan.md §二）
