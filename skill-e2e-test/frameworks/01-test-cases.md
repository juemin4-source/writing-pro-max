# 01 — 测试用例（每个 skill 的 E2E 场景）

> 本文件是 SKILL.md「输入与模式」的操作细则，不独立成立。每个用例 = 夹具 + 模拟导演脚本 + 阶段验收点 + 预期产出清单。

## 通用导演脚本约定

模拟导演画像：**刻薄、挑剔、高要求**——一个懂行但难伺候的导演。E2E 测的是"skill 扛不扛得住高要求用户"，不是"skill 与好脾气用户相处"。温和用户测不出协议漏洞，刻薄用户才能。

### 画像行为模式（每个用例至少触发 3 种）

```
① 拒绝第一稿：AI 的第一个提案/草案直接拒（"这个太俗了，再想"）→ 逼 AI 出多个候选
② 连环返修：一次 [改:] 之后继续挑（"改是改了，但……"）→ 测返修上限 2 轮与终裁路径
③ 质疑判断依据："你凭哪条理论说这个成立？引用原文" → 测"必须交代判断依据"
④ 抽象批注："这不行""重写一下"（无细节）→ 测路由澄清（置信度低时先回问，不猜）
⑤ 抓自相矛盾："你前面说暗动要藏，这里又让它亲口说出来了" → 测跨阶段一致性
⑥ 高要求验收：用理论术语精准挑错（"这个'私'和'执'脱节了"）→ 测 AI 能否接住专业反驳
⑦ 拒绝敷衍：AI 用"感觉更好了"解释修改时直接打回（"理由呢"）
⑧ 陈词滥调敏锐感知：任何阶段嗅到 cliché 立即打回——但打的是**处理方式的套路**，不是题材本身
   （题材无新旧，写法有死活：'牺牲前必说遗言''真相总在最后一章揭晓''主角一开口观众知道下句'
   ——《故事天演论》S 熵判词："反派一抬手，观众就知道他要打偏，这叫垃圾"）
   → 测 AI 能否识别套路性处理并逃离（不是拒绝题材）
⑨ 悬疑内驱："一切创作都是悬疑"——每阶段验收必问：读者现在想探索的真相是什么？会不会一眼望到头？
   答案太明显/可预测 = FAIL → 测"悬念链条"是否在场
⑩ 低入口高经验 + 拒谜语人：入口四件事（缺什么/要什么/什么挡/为什么值得看）必须清楚可答；
   故作高深/信息藏起来不给 = 谜语人 = 伪高级，打回 → 测低入口与藏露分寸的平衡
⑪ 允许涌现：大纲落地前涌现出的更好情节被导演接受并鼓励（"这个比我之前定的好——大纲改"）
   → 测流程是否允许创作中途生长（偏离大纲 = 机会不是错误）
```

所有用例包含：

```
① 通过路径：关键决策点选"通过"（验证正常链路）
② 返修路径：刻薄批注触发返修（含一次连环返修，验证 2 轮上限与终裁）
③ 一次选择框交互：输出位置/导演指令必须弹 AskUserQuestion（协议检查）
④ 至少一次质疑判断依据（测"必须交代依据"条款）
```

### 画像示例（可直接用的批注弹药库）

```
- "第二个方案和第一个内核一样，只是换了层皮。重想。"
- "这句前提的张力埋在第三句了，前三句是废话。压缩。"
- "你引用的是命运篇哪一节？把验收句原文给我。"
- "这个'私'和'执'是脱节的——他怕失去稳定，但执却是'必须有用'，两者怎么接上的？"
- "改是改了，但改完的涟漪呢？谁的位置变了？你只改了表面。"
- "这里太顺了。按失候清单，春太顺是红牌——你怎么看？"
```

## 用例 1：novel-original-writing（原创剧本流）

| 项 | 内容 |
|----|------|
| 夹具 | `fixtures/concept-e2e.md`（测试概念） |
| 覆盖 | A-G 七阶段全流程（full）；smoke = A 种子期完整 + B/C/D/E/F/G 每阶段抽样验收 |
| 返修点 | C 阶段（执七问第 3 问羞耻载体不可拍 → `[改:私-6 载体改可拍动作]`） |
| 验收点 | A：16 条可判定检查（低入口/失真/生成力/场域/暗动）；B：硬规则 6 + 推导七步；C：38 问无空答 + 执四形态；D：24 节气验收 + 失候 0 命中；E：场景卡 9 字段 + 剧本硬规则；F：四件套齐全；G：大雪/冬至 gate + 归藏三查 |
| 质量门 | 20 条逐条验收（[导演] 条目标注"模拟导演裁决"） |
| 预期产出 | checkpoints/00-seed.md … 08-ending.md + director-log.jsonl（rationale 非空）+ 剧本 |
