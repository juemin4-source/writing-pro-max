# E2E 测试概念（novel-original-writing 种子期夹具）

> 本夹具专供 E2E 测试使用，与真实创作隔离。概念选取原则：**有生成力但不过度复杂**——能测出种子期 13 轮交互的完整路径，又不会让测试无限展开。模拟导演画像：**刻薄、挑剔、高要求**（见 01-test-cases.md）。

## 概念

> 一个能听见植物说话的女孩，发现后院的老槐树知道全家三代人的秘密——包括一个谁都不愿提起的失踪者。

## 模拟导演的初始素材（供种子期轮 1 使用）

- 作者愿望（模拟）：想写"家族秘密"；喜欢"日常里藏着异物"的氛围；想写一个"被轻视的孩子突然成为唯一知情者"的故事
- 外部材料（模拟）：后院老槐树、三代人的旧宅、失踪者
- 深处问题（模拟）：秘密是保护还是债务？

## 导演脚本关键回答（种子期，刻薄画像）

| 轮 | 模拟回答（挑剔行为） |
|----|---------------------|
| 轮 1 愿望 | 用上列初始素材；反问 AI："别急着分类，先告诉我这几个材料哪个最能生事"（测 AI 是否急着分类而非追问） |
| 轮 2 八象 | 拒绝第一稿："道+和太常规了。这个组合几乎每个家庭剧都用。你还有别的组合吗？生和名呢？"（①拒绝第一稿） |
| 轮 3 六变一常 | 接受"扰"但追问："扰和异在这棵树上的区别是什么？树不是外来的，它一直在——这到底是扰还是常里长出的变？你引用六变一常的定义说清楚"（③质疑依据） |
| 轮 4 前提 | 从 AI 草案中挑刺："第二版的张力在'只能听不能说'，你把它埋在第三句了。前三句是废话，压缩到一句。重写"（④抽象批注+高要求） |
| 轮 5 追问 | 补充追问："失踪者是自己走的还是被赶走的？"然后反问："我这个问题算剧情追问还是主题追问？你按三追问的标准判"（③质疑依据） |
| 轮 6 验收 | 失真检查时逼问："'秘密揭示的后果'——你检查过了吗？还是默认它有了？后果具体落到谁身上？"（⑦拒绝敷衍） |
| 轮 7 私生人物 | 拒绝 AI 的 2 个样本："第二个和第一个内核一样——都是'怕失去'，只是换了表面。私的内核只有一个。重捏"（①拒绝第一稿）；后补 1 个自己的："想证明自己没有疯"型 |
| 轮 8 场域 | 确认旧宅+后院+家族关系网；追问："你列的三条规则里，哪条是压住欲望的？后院的规则只是背景"（⑤抓逻辑漏洞） |
| 轮 9 生长 | 主路选"向内逼近"；反问："向内逼近到哪一层？逼近到'她发现秘密也在保护她'算吗？还是必须到'她成为秘密的一部分'？"（高要求验收） |
| 轮 10 值得写 | 三问回答；打回抽象："'家族沉默作为结构'——太抽象了，落到一个具体物件上。树是物件，沉默不是"（⑥专业挑错） |
| 轮 11 尺度 | 确认小尺度 → 短片；追问："小尺度但三代人的秘密，信息量会不会超载？你按清明的验收句判一下"（③质疑依据） |
| 轮 12 入口 | 选从冬入；挑剔："从冬入最怕慢。你打算在哪一段放'雪下有声'？树开口前五页都是日常的话我直接拒"（④抽象批注） |
| 轮 13 暗动 | 确认"树一直听得见"为雪下有动；连环追问："暗动有了，但暗动有没有'说得太明'？你刚才自己说树听得见，这算露了还是藏了？"（②连环返修） |

## 返修路径设计（C 阶段）

```
[改:执-3 羞耻的载体不可拍——"她不想被当成疯子"是心理描写，换成一个可拍的动作/物件]
→ 修后连环：[改:改是改了，但新载体和她的"私"（怕被轻视）是脱节的。再想]
→ 验证：2 轮上限到达后，AI 是否按终裁决策集处理（接受现状/召评审团/删减/终止）而非继续猜
```

## 测试意图

- 测：共创模式在刻薄用户下是否扛得住（AI 每轮是否主动提议 ≥2 候选、被拒后是否重出而非放弃）
- 测：AI 是否每处判断都交代理论依据（引用条款/验收句原文）
- 测：13 轮是否逐轮等用户回答（不一口气编）
- 测：返修协议（2 轮上限 + 终裁 + before/after diff）
- 测：跨阶段一致性（⑤抓自相矛盾时 AI 能否自洽）
