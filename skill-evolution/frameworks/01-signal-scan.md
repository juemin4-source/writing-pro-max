# 01 — 信号扫描（三类信号的提取规则与证据格式）

> 本文件是 SKILL.md「流程① 信号扫描」的操作细则，不独立成立。

## 一、三类信号

### 1. 纠正信号（最高价值）

用户说"不对/不要/应该/别这样/限制太死/没用上/这不是我要的"的场合。每条记录：

```
纠正信号
- 原行为：AI/技能当时做了什么（可引用文件或对话）
- 纠正：用户怎么说的（原话引用）
- 根因：为什么错了——理论缺口/交互缺口/流程缺口/理解偏差
- 修复：已应用 / 待应用 / 已由新行为取代
```

示例（真实发生过）：
```
- 原行为：A 种子期用 @山音 STC + 悬念五类，未接用户自著理论
- 纠正："故事前提那块没有用到我的理论"
- 根因：理论缺口——《故事天演论》第五-七章有完整前提方法论，未纳入
- 修复：已应用（00-seed.md 重写，13 节全理论化）
```

### 2. 风格信号

用户偏好，不需要纠正也会出现的稳定倾向。来源：用户主动表达（"我喜欢…"）、交互选择（选了选项 A 而非 B）、行为模式（多次要求某种格式）。每条记录：

```
风格信号
- 信号：用户偏好什么（具体）
- 证据：原话/行为（≥2 次或显式声明）
- 维度归类：理论偏好/交互偏好/质量偏好/文档习惯/交付习惯
```

### 3. 新约定

用户定下的规则（明示或默示），通常以"以后/默认/应该"开头。每条记录：

```
新约定
- 规则：原文或精确转述
- 场合：什么时候定的
- 状态：已写入哪个 skill / 待写入
```

## 二、扫描范围

- 会话内：本轮对话全文（默认）
- 跨会话：指定范围时读 memory（MEMORY.md 索引）与 tasks/reports/ 的近期报告
- 素材源：用户消息中的纠正/偏好/决定、用户对交付物的修改（如用户自己改了 novel-review 加文笔层——这是强信号：用户主动扩展了 skill）

## 三、证据纪律

1. 每条信号必须可引用：原话（短句引用）或行为描述（"用户手动改了 04-report.md 加文笔层"）
2. 无证据的猜测不写入——宁缺毋滥
3. 用户对文件的直接修改（Edit/Write/重命名）是最高置信度信号（比口头偏好更硬）
4. 区分：**用户纠正 AI 的行为**（AI 改）vs **用户纠正技能的设计**（skill 文件改）——后者直接进优化提案

## 四、输出

扫描结果 = 信号清单（按价值排序：已修复的纠正 < 待应用的纠正 < 用户主动扩展 < 新约定）。信号清单进复盘报告；有价值的进风格档案（02）；可执行的进优化提案（03）。
